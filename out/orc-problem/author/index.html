    Editor · Orc Problem Field Manual

    Runs the Orc Problem Field Manual; every figure is traced to Steam's public data, a named player guide or Mumpitz Games' own text before printing.

    What this site covers

    Orc Problem Field Manual is an independent reference for Sir, We Have an Orc Problem (Mumpitz Games), kept deliberately small: a page exists only when there is sourced material to fill it. It has no affiliation with Mumpitz Games — see the disclaimer.

    How pages are checked

    Every page starts from a named primary source — Steam's public APIs, a Steam guide with a named author and posting date, or Mumpitz Games' own published text — and lists which ones it used at the bottom under Sources checked for this page. Numbers travel with the date they were read, because unlock percentages and review scores move daily. Where two sources disagree, both are printed rather than one being picked; where nobody has published a figure, the page says so instead of estimating. The full rules, including how corrections are handled, are in the editorial policy.

    Corrections and contact

    If a page contradicts the live game, that is worth reporting — reports with a screenshot or a source link are the fastest to act on. Contact
