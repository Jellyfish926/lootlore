3:T69f,<p><em>Last reviewed: 11 September 2026 · Newest game update reflected: 2026.08.18.12.05 (18 August 2026).</em> This site uses a lot of shorthand — turret names, achievement titles, level numbers, community slang like "the lips" — without stopping to define it on every page. This glossary collects all of it in one A–Z list, each entry pointing back to the page where it is explained in full.</p>

<h2>A–D</h2>
<p><strong>Ability</strong> — one of the four click-triggered attacks (missile launcher, strafing run, nuke, orbital cryo beam) alongside the seven turrets. Two are capped at three uses per map. Numbers on the <a href="/towers/abilities/">abilities page</a>.</p>
<p><strong>Against All Odds</strong> — the achievement for clearing level 6, sitting around 27–30% unlock depending on the read date. See the <a href="/levels/all-achievements/">all achievements page</a> for the current figure.</p>4:T2839,<p><strong>Cannon</strong> — the highest-penetration turret (31), 34.5 DPS at 2 shots/sec, with a larger fifth shot. A <strong>power</strong> turret in the <a href="/towers/turret-roles/">turret roles</a> framework. Full stats on <a href="/towers/all-turrets/">all turrets</a>.</p>
<p><strong>Chokepoint</strong> — a map location narrow enough that only a handful of orcs pass through at once. The <a href="/towers/orc-flow-mechanic/">orc flow mechanic page</a> explains why killing orcs before one does almost nothing, while killing them in or past one is where turrets matter.</p>
<p><strong>Cleanup (role)</strong> — one of three turret roles, alongside power and support. Cleanup turrets — gunner and tesla coil — catch whatever leaked past the damage line. Defined on <a href="/towers/turret-roles/">turret roles</a>.</p>
<p><strong>Constraint achievement</strong> — an achievement forbidding something (abilities, turret variety) rather than just asking you to progress. Eight of the eleven achievements are constraint achievements; see <a href="/levels/all-achievements/">all achievements</a>.</p>
<p><strong>DPS</strong> — damage per second. The stat table on <a href="/towers/all-turrets/">all turrets</a> lists it per turret, but the page warns that penetration matters more than DPS against a dense wave, since a shot that stops at the third orc never reaches the fourth.</p>
<h2>E–G</h2>
<p><strong>Elemental Carnage</strong> — the achievement for clearing a level using only the flamethrower, tesla coil and orbital cryo beam. Sits at 18.5% unlock. Covered on the <a href="/towers/tesla-coil/">tesla coil page</a> and <a href="/levels/all-achievements/">all achievements</a>.</p>
<p><strong>Fine, I'll Do It Myself</strong> — the official name of the no-turret, abilities-only achievement, at roughly 20–22% unlock. Full breakdown on the <a href="/levels/no-turret-run/">no-turret run page</a>.</p>
<p><strong>Flamethrower</strong> — a <strong>support</strong> turret dealing almost no direct damage (0.6 per tick) but applying a damage amp and a chance to not consume pierce to whatever it burns, which quietly strengthens gunners and lasers firing through the same zone. Stats on <a href="/towers/all-turrets/">all turrets</a>.</p>
<p><strong>Four-tified</strong> — the official name of the four-turret-type, no-ability achievement, the rarest in the game at around 10.8–12.2% depending on read date. Explained on <a href="/levels/level-6-1-four-turret-types/">level 6.1</a>.</p>
<p><strong>Fully Loaded</strong> — the achievement for buying every upgrade, 19.5% unlock. It cannot be shortened by skill, only playtime — see <a href="/levels/all-achievements/">all achievements</a>.</p>
<p><strong>Gotta Start Somewhere</strong> — the achievement for clearing the first level, unlocked by roughly 97% of players. The easiest achievement in the game.</p>
<p><strong>Grenade Launcher</strong> — a <strong>support</strong> turret applying a 60% slow for 3 seconds in a 13 m radius; slowed orcs take 30% more damage. Shows up in nearly every hard-level build documented on this site, from <a href="/levels/level-3-2-difficulty-spike/">3.2</a> to <a href="/levels/level-5-2-the-lips/">5.2</a> to <a href="/levels/level-6-1-four-turret-types/">6.1</a>.</p>
<p><strong>Gunner</strong> — the fastest-firing turret (24 shots/sec) but with only 3 penetration, so its volume is spent on orcs already dead or already blocked in a dense column. Debated between cleanup and power in the <a href="/towers/turret-roles/">turret roles</a> framework.</p>
<h2>H–M</h2>
<p><strong>Laser</strong> — the longest-range turret (550 m) with 15 bounces, ricocheting down a corridor to hit the same column repeatedly. A <strong>power</strong> turret; numbers on <a href="/towers/all-turrets/">all turrets</a>.</p>
<p><strong>Level editor</strong> — the only roadmap item Mumpitz Games has stated publicly, announced in the 18 August 2026 patch notes with no date attached. Covered on <a href="/platform/update-history/">update history</a>.</p>
<p><strong>"The lips"</strong> — the community name for level 5.2's two narrow entry points, where the level is won or lost. Full explanation on the <a href="/levels/level-5-2-the-lips/">5.2 page</a>.</p>
<p><strong>Meta-progression tree</strong> — the upgrade tree that unlocks and levels up turrets and abilities, funded by resources earned from <strong>every run, won or lost</strong>. Details on the <a href="/towers/upgrade-grind/">upgrade grind page</a>.</p>
<p><strong>Missile launcher</strong> — the only unlimited-use ability, firing automatically after one click for 79.5 damage in a 20 m radius plus shrapnel. Numbers on the <a href="/towers/abilities/">abilities page</a>.</p>
<p><strong>Mortar</strong> — a <strong>support</strong> turret with modest damage (32 DPS) whose real value is knockback across a 28 m blast, which can physically hold a chokepoint shut. Stats on <a href="/towers/all-turrets/">all turrets</a>.</p>
<h2>N–P</h2>
<p><strong>No-turret run</strong> — a level cleared with zero turrets, abilities only. The achievement for it (<em>Fine, I'll Do It Myself</em>) sits around 20–22% unlock, lower than several no-ability turret constraints. See the <a href="/levels/no-turret-run/">dedicated page</a>.</p>
<p><strong>Nuke</strong> — a limited ability (three per map), 260 damage across a 250 m radius. Also the basis of the <em>Overkill</em> achievement (666,000 damage with one nuke). Covered on <a href="/towers/abilities/">abilities</a>.</p>
<p><strong>One Is Enough</strong> — the single-turret, no-ability achievement, roughly 25% unlock, typically attempted on level 1.1.</p>
<p><strong>Orc flow / orc overflow</strong> — the community term for how orcs move: like fluid seeking any gap it can pass through, not a queue. First named by a player in a feedback thread; full explanation on the <a href="/towers/orc-flow-mechanic/">orc flow mechanic page</a>.</p>
<p><strong>Orbital cryo beam</strong> — the fourth ability, a 6-second effect held for 4.4 seconds that deals 50 damage on defrost. Its value is time bought, not damage — especially in a <a href="/levels/no-turret-run/">no-turret run</a>, where it is the only thing slowing a wave.</p>
<p><strong>Overkill</strong> — the achievement for dealing 666,000 damage with a single nuke, around 36–40% unlock, the most-cleared constraint achievement in the game.</p>
<p><strong>Penetration</strong> — how many orcs a single shot passes through before stopping. The <a href="/towers/all-turrets/">all turrets page</a> calls it "the number that decides everything," since a turret's fire rate is close to meaningless against a column deeper than its penetration.</p>
<h2>R–S</h2>
<p><strong>Resource economy</strong> — the game's meta-currency system, earned from every run regardless of outcome. Because losing still pays, the <a href="/towers/upgrade-grind/">upgrade grind page</a> treats "stuck" as an upgrade problem, not a skill one.</p>
<p><strong>Slow (grenade launcher effect)</strong> — a 60% movement reduction for 3 seconds that also makes affected orcs take 30% more damage. The most-cited mechanic across this site's hard-level pages: <a href="/levels/level-3-2-difficulty-spike/">3.2</a>, <a href="/levels/level-4-2-chokepoints/">4.2</a>, <a href="/levels/level-5-2-the-lips/">5.2</a>, <a href="/levels/level-6-1-four-turret-types/">6.1</a>.</p>
<p><strong>Specialist</strong> — the one-turret-type, no-ability achievement, roughly 22.5% unlock, typically attempted on level 3.1.</p>
<p><strong>Steam Deck: Playable</strong> — Valve's middle compatibility rating for this game, below Verified. It passes both performance checks and fails on controller-glyph mismatch and small interface text. Full detail on <a href="/platform/pc-and-steam-deck/">PC and Steam Deck</a>.</p>
<p><strong>Strafing run</strong> — a limited ability (three per map) covering a 110 m by 398 m corridor for 142 damage across 105 bullets. Shaped for lanes, not open ground. Numbers on <a href="/towers/abilities/">abilities</a>.</p>
<p><strong>Supporter Pack</strong> — the game's only DLC, $2.99, three cosmetic items (Blue Flames, Space Orcs, Space Background) with no gameplay effect. Described by the developers as a tip, not content. Full page: <a href="/platform/supporter-pack/">Supporter Pack</a>.</p>
<p><strong>Support (role)</strong> — the turret role that changes how a wave moves rather than killing it outright: grenade launcher, mortar and flamethrower. Defined on <a href="/towers/turret-roles/">turret roles</a>.</p>
<h2>T–V</h2>
<p><strong>Tesla coil</strong> — the only turret with a full 360° aim arc, chaining across 12 targets per shock. A <strong>cleanup</strong> turret best placed behind the main damage line, not on it. Full breakdown on the <a href="/towers/tesla-coil/">tesla coil page</a>.</p>
<p><strong>The Real War Begins Now</strong> — the achievement for clearing the third level, around 87–88% unlock.</p>
<p><strong>Triple Threat</strong> — the three-turret-type, no-ability achievement, roughly 15.6–17.2% unlock, typically attempted on level 5.1.</p>
<p><strong>Upgrade branch</strong> — a specific line within the meta-progression tree (the laser's bounce, the grenade launcher's slow). Multiple pages, starting with <a href="/levels/level-3-2-difficulty-spike/">3.2</a>, find which branches are upgraded matters more than total upgrade level.</p>
<p><strong>Vulkan 1.3</strong> — the graphics API version this game requires and the only real barrier to running it, according to the <a href="/platform/pc-and-steam-deck/">PC and Steam Deck page</a>. Everything else in the minimum spec (4 GB RAM, any 64-bit CPU, 200 MB storage) is trivial.</p>
<h2>What we have not documented</h2>
<p>Percentages above shift by a point or two between entries because Steam's achievement API was re-read on different dates across this site's build history — the <a href="/levels/all-achievements/">all achievements page</a> and the <a href="/levels/achievement-tracker/">achievement tracker</a> carry the most current figures.
