    Untitled Wheelie Game Group, Discord and Codes Info

    By Jellyfi · Last reviewed 2026-09-30 · Checked on version 2026-09-30 update

    Scope: Group data from the Roblox groups API on 2026-09-30; the game's social links need a Roblox login and were not read

    Key points

    • The game is owned by the Roblox group Untitled Wheelie Group, which describes itself as the Official Group and had over 700,000 members.
    • The game's own social links need a Roblox login, so we could not read them. Code sites link a Discord invite (discord.com/invite/QHuDU7GHSB) created by a Discord account named fireblock373, the same name as the group owner — a strong sign it is official, but Roblox itself does not show it publicly.
    • No code appears in the game description or on the group page, so we list none.
    • Wheelie District is a different game from a different group.

    The official home of Untitled Wheelie Game is the Roblox group Untitled Wheelie Group, which owns the game and calls itself the "Official Group". It had 703,842 members on 30 September 2026. Third-party guides link a Discord invite made by an account with the owner's name; we could not confirm it from Roblox itself, and we list no codes.

    Which Roblox group is official?

    Only one group owns the game, and the Roblox API names it as the creator. Its public details on 30 September 2026:

    DetailValue
    NameUntitled Wheelie Group
    Group descriptionOfficial Group
    Ownerfireblock373 (display name "fire")
    Members703,842
    JoiningOpen to anyone
    Pinned announcementNone
    Public gamesThis game only (the group also owns 33 other experiences that are not public)

    You can find it on Roblox as Untitled Wheelie Group. Neither the group nor the owner account carries Roblox's verified badge, so check the group number (84540135) in the address bar rather than trusting the name alone.

    What do the group roles tell you?

    The group's public role list shows how the team is organised, without naming individuals.

    RoleMembers
    Owner1
    Admin0
    Tester1
    Content Creator10

    A "Content Creator" role with 10 members suggests the developer works with a small group of video makers. That is our reading of the role name; the group does not describe the role or name the channels.

    Is there an official Discord server?

    Roblox shows an experience's social links only to signed-in users, and the public data we can read does not include a Discord address. Code sites link discord.com/invite/QHuDU7GHSB and call it the official server. The invite was created by a Discord account named fireblock373, matching the group owner's Roblox name, and the server calls itself "Untitled Wheelie Game Official". That is good evidence but not proof. Check the social links on the Roblox page while signed in to be sure.

    Our advice: open the game on Roblox while signed in and use the social link buttons on that page. A link found there comes from the developer; a link on a random site may not.

    Is there an Untitled Wheelie Game testing server?

    People search for one, but we found no public testing game. The group lists only one public experience, and a Roblox search for a testing version returned the main game. The group does have a Tester role with one member, so testing seems to happen privately.

    Are there Untitled Wheelie Game codes?

    Not that we can confirm. The game description contains no codes, the group has no pinned announcement, and we could not read a public group wall. Code lists on third-party sites agree with each other — one cash code marked active and two marked expired — and say codes are announced in the Discord and group announcements, but none links to a specific developer post. We only publish a code after seeing it in an official source; until then, check the group page and the social links on the game page yourself.

    How do you avoid the wrong game?

    Another Roblox experience, "[AI COPS + MORE👮] Wheelie District 🏍️", is made by Wheelie District Studios. It also features wheelies and AI cops, and many code pages online are about it, not this game. The quickest check is the creator line on the Roblox page: this game says Untitled Wheelie Group. The cops and fines guide covers the police side of this game.

    What about scripts and exploits?

    We do not cover them. Scripts break Roblox's Terms of Use and can get an account banned. If you want to earn faster, the money guide covers the legitimate options, and the update history shows what the developer has added.
