## 砍掉的词 / 页(留痕)

| 词 / 页 | 为什么砍 |
|---|---|
| codes 页 | 官方来源 0 个码(描述 8 行无码;群组 description 空、shout null);别站也没有码页可交叉。硬做只能是「Active Codes: 0」→ 不建;hub 用一节说明原因 |
| written test answers 单独成页 | 0 个来源(连 B/C 都没有)。题目、题数、答案全部未知 → 不建,连草稿也不生成;进游戏核实后再建 |
| all endings 单独成页 | 一手只有 Honor Roll 与 Towed 两个名字,没有触发条件 → 单页必薄,合并进 driving-test;拿到全表后拆成 /endings/ |
| all cars list 单独成表页 | 一手只有数量 18、档位名 Epic、商品 Golden Supercar 🏆 → cars 页写这些并明说没有车表;车名进游戏核实后补表 |
| examiner 单独成页 | 一手只有 1 行描述 + 2 个商品(共约 6 条事实),单页不到 800 词 → 合并进 driving-test |
| badges 页 | 官方徽章 0 个(4 次读取均为空)→ 不建 |
| updates / patch notes 页 | 官方活动 0 条;没有更新公告。上架时间线(3 行)并进 hub 与 shop |
| tier list / best car 榜 | 没有任何车的数值;唯一的「best」是商品描述里开发者自己的说法 → 不做榜,写进 cars 页并标明是开发者说法 |
| script / auto farm / pastebin | 外挂,违反 Roblox 条款,总站不做 |
| the loop 单独成页 | 只有一个地名 → 写进 cars 页的未公开清单 |
| 真实驾照词(get your driver's license online / near me / in texas …) | 与游戏无关,且是 YMYL 政务词 → 全部剔除,页面里不蹭 |
