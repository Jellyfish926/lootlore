    Orc Problem Mobile: Is There an Android Version?

    By Jellyfi · Last verified 2026-08-12

    Last reviewed: 1 September 2026 · Newest game update reflected: 2026.08.18.12.05 (18 August 2026). No. There is no Android version, no iOS version, and no announced plan for either. Steam's own platform field for this game returns Windows and Linux only, with macOS explicitly false. Nothing in the store data points at a phone or tablet build.

    We checked the developer's side too. Across all twelve official Steam announcements — from the playtest in May 2026 through the update on 5 August 2026 — the words mobile, Android, iOS, phone and tablet do not appear once. Mumpitz Games has not teased a port, given a release window, or answered the question publicly.

    Why so many people assume it is a phone game

    This is not a silly question, and the game's own store data explains why it gets asked so much. Steam lists it with a Mouse Only Option, Playable without Timed Input, and Save Anytime.

    That is the exact feature profile of a mobile title. Nothing here demands a keyboard, precise timing, or an uninterrupted session — you click to place turrets, click to fire abilities, and stop whenever you want. A tower defence with an incremental-style upgrade tree is also the genre people most associate with phones.

    So the instinct is reasonable. The build just does not exist.

    What the APK and "free download" sites are

    Search suggestions for this game include mobile download and mobile free download, which means those pages exist and are getting traffic. They are not from Mumpitz Games.

    The game is a paid PC title at $9.99 and it is sold through Steam. There is no official free build, no official APK, and no legitimate mirror. Anything offering an Android package of this game is either a mislabelled different game, a repackaged file, or worse — and installing an APK from an unknown source is a considerably worse idea than waiting.

    We are not linking to any of them. If a mobile version is ever announced, it will show up in the Steam announcement feed and on the developer's own channels first.

    The handheld answer that does exist

    If what you actually want is to play this lying on a couch rather than specifically on a phone, there is a real option: the game has a native Linux build, and its stated minimum Linux OS is SteamOS 3.8 or similar. That is Steam Deck's operating system.

    Valve's compatibility report puts it at Playable — the middle rating, not Verified. The report is specific about why, and both reasons are interface problems rather than performance ones:

    TestResult
    Default configuration is performantPass
    Default controller config fully functionalPass
    Controller glyphs match the DeckFail
    Interface text is legibleFail

    In plain terms: it runs fine and the controls work, but the on-screen button prompts show the wrong icons and the UI text is small enough that Valve flagged it. For a game where you are reading turret stats and upgrade costs, that second one is the real cost.

    Our PC and Steam Deck page has the full requirements if you want to check a specific machine.

    Would it work on a phone if it were ported?

    Probably, and that is the frustrating part. The install is 200 MB, it needs 4 GB of RAM, and there is no multiplayer component to maintain. The heaviest requirement is Vulkan 1.3 support, which modern phone hardware generally has.

    None of that means a port is coming. Mumpitz Games is a small self-publishing studio, and the game sold 100,000 copies in its first four days on PC — a studio in that position usually spends the next few months on updates for the platform that is already working.

    We will update this page if that changes. We are not going to guess at a date.

    If you are here for something else

    If you landed on this page because you were looking for the game itself, it is a single-player PC tower defence released 28 July 2026, currently sitting at Very Positive on Steam. The turret guides and level and achievement guides are the parts of this site worth your time.

    If you were looking for a way to play it without buying it — there isn't one, and the sites claiming otherwise are not doing you a favour.
