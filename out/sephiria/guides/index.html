    Where to Start: A Sephiria Reading Order

    Which Sephiria wiki pages to read first, in order, from your first run to a Hard Mode tier 50 clear — with a reason for every step and an FAQ.

    One loop, seven angles

    Sephiria is built on a single loop: climb the tower, die, carry Sapphires back, buy something permanent, climb again. The pages in this section cover that loop from every angle it can be misunderstood from.

    The beginner guide walks a run end to end. The inventory grid page explains the mechanic that decides most runs. The combos page covers the tag system that decides your damage. Destiny Inscription is where the Sapphires go, talents are what they unlock, Hard Mode is what you do afterwards, and the co-op page covers what changes with up to four players. The achievements page turns Steam's unlock rates into a map of where players actually stop, and the costumes page prices the stat trades hiding in the wardrobe.

    Start where your run is failing

    If you have not played yet, read the beginner guide and nothing else — the rest will make more sense with one run behind you.

    If runs keep ending on the same floor, the answer is almost never reflexes. Floor 3 is where base enemy Defence jumps from 18 to 46, and builds that die there are usually carrying artifacts at level 0 rather than needing a better weapon. Go to the inventory grid page.

    If you are clearing chapters but stalling at boundaries, your weapon line, talent spread and combo plan have stopped agreeing with each other. That is the builds section.

    The mistake nearly everyone makes first

    Treating the bag as storage. Artifacts sit in a grid, tablets push level values onto specific cells, and where an item sits changes what it does. Three well-placed artifacts beat eight scattered ones, and the game does very little to tell you this.

    The second most common mistake is skipping Anvils. Weapon upgrades gate on stage progression, so skipping them early can stop later anvils from appearing at all.

    Our sourcing rule, stated plainly

    Every page names what it was checked against — TEAM HORAY's own patch notes and store text, player-written Steam guides, Steam's public achievement statistics, or an open community dataset whose numbers we verified against official patch notes before citing it.

    When something is not documented anywhere we trust, the page says so and leaves it blank. You will find boss attack patterns, complete artifact tables and weapon tier lists on other Sephiria sites. We do not have verified sources for any of those three, so we do not publish them.

    Sephiria left Early Access on 31 July 2026. Most of what currently circulates about it was generated from the store page by sites that cannot tell you where a number came from, and several have propagated boss names that do not exist in the game.

    Corrections

    If something here is wrong, the contact page reaches us. Corrections get checked against a source before they go live, and a patch that invalidates a page gets noted in the patch notes section rather than quietly edited away.
