3:T8c3,<p><em>Last reviewed: 1 September 2026 · Newest game update reflected: 2026.08.18.12.05 (18 August 2026).</em> <strong>If your PC can do Vulkan 1.3, it can run this game.</strong> Everything else on the requirements list is trivially low: any 64-bit x86 processor, 4 GB of RAM, and <strong>200 MB</strong> of storage. There is no GPU model named anywhere in the minimum spec.</p>
<p>That makes this one of the easier games to check compatibility for. You are not asking "is my card fast enough", you are asking "is my driver new enough", and those are very different questions.</p>

<h2>The official requirements, verbatim</h2>
<p>These come straight from the Steam store data, not from a spec-scraping site.</p>
<div class="tw"><table><thead><tr><th></th><th>Minimum</th><th>Recommended</th></tr></thead><tbody><tr><td>OS</td><td>Windows 10</td><td>Windows 11</td></tr><tr><td>Processor</td><td>Any x86_64 CPU</td><td>Any x86_64 CPU</td></tr><tr><td>Memory</td><td>4 GB RAM</td><td>4 GB RAM</td></tr><tr><td>Graphics</td><td>Vulkan 1.3 support</td><td>Dedicated graphics card with Vulkan 1.3 support</td></tr><tr><td>Storage</td><td>200 MB</td><td>200 MB</td></tr></tbody></table></div>
<p>Note what does <em>not</em> change between the two columns. The processor, memory and storage are identical; the only <a href="/towers/upgrade-grind/">upgrade</a> Mumpitz Games asks for is a dedicated GPU instead of integrated graphics. That is an unusually honest requirements table — most studios pad the recommended column.</p>4:T1003,<h2>Vulkan 1.3 is the only thing that can actually stop you</h2>
<p>Vulkan 1.3 was released in early 2022. In practice that means a GPU driver from roughly 2022 onwards on NVIDIA, AMD and Intel alike.</p>
<p>If the game refuses to launch on hardware that looks powerful enough, the driver is the first thing to check, not the card. Older integrated Intel graphics and pre-2020 driver branches are the common failure case, and updating the driver fixes it more often than not.</p>
<p>There is no DirectX fallback listed, so this is not optional.</p>
<h2>Linux and SteamOS</h2>
<p>The game ships a <strong>native Linux build</strong>. Steam's Linux requirements name <strong>SteamOS 3.8 or similar</strong> as the minimum OS, with the same 4 GB / Vulkan 1.3 / 200 MB figures.</p>
<p>Naming SteamOS specifically in the Linux column is a deliberate signal. It means the handheld case was considered rather than left to Proton compatibility layers, which matters for battery life and for whether things break after a system update.</p>
<p><strong>There is no macOS build.</strong> Steam's platform field returns mac as false, and no Mac requirements are published. Apple Silicon users have no supported path here.</p>
<h2>The Steam Deck rating is Playable, and the reasons are specific</h2>
<p>Valve's compatibility report resolves this game to <strong>Playable</strong> — the middle tier, below Verified. The report lists four individual test results, and reading them is more useful than the badge:</p>
<ul><li><strong>Default configuration is performant</strong> — pass</li><li><strong>Default controller configuration is fully functional</strong> — pass</li><li><strong>Controller glyphs match the Deck's device</strong> — fail</li><li><strong>Interface text is legible</strong> — fail</li></ul>
<p>So performance is not the problem and neither are the controls. What Valve flagged is presentation: the game shows the wrong button icons, and the interface text is too small at the Deck's screen size.</p>
<h2>Whether that matters depends on how you play</h2>
<p>For a shooter, wrong glyphs would be a nuisance and small text would be survivable. Here it is the reverse. This is a game where you read turret stats, upgrade costs and level numbers constantly — small text is the exact thing you cannot easily work around.</p>
<p>Players who care about squeezing the numbers will find the Deck frustrating. Players who already know their build and want to grind resources on the couch will barely notice, since the mouse-only control scheme maps cleanly to the trackpad.</p>
<p>If you want it handheld, it works. Go in expecting to squint at the upgrade tree.</p>
<h2>What else the store data tells you</h2>
<p>The game is <strong>single-player only</strong> with <strong>11 Steam <a href="/levels/all-achievements/">achievements</a></strong>, and it supports <strong>Steam Cloud</strong> and <strong>Family Sharing</strong> — so a save started on a desktop continues on a Deck without any manual copying.</p>
<p>It ships with <strong>13 languages</strong>: English, French, Italian, German, Spanish (Spain), Dutch, Japanese, Korean, Polish, Brazilian Portuguese, Russian, Simplified Chinese and Traditional Chinese. That is broad for a small studio and suggests the text volume is low, which is consistent with a 200 MB install.</p>
<p>There is <strong>no official website</strong> listed on the store page. Steam's announcement feed is the only first-party channel we can point at, which is worth knowing if you go looking for <a href="/platform/update-history/">patch notes</a>.</p>
<h2>What we cannot tell you</h2>
<p>We have not benchmarked this ourselves on any specific hardware, and we do not have frame-rate figures for the Deck or for integrated graphics. Valve's report has no published test date, so we cannot say which build it was run against — and the game has already been updated once since launch, on 4 August 2026.</p>
<p>If a specific machine is borderline, the two-hour Steam refund window is a more reliable test than any requirements table, including this one.</p>6:["category","platform","d"]
