# +1 Stone Skipping Codes, Meow Labs Group and Discord

There are no +1 Stone Skipping codes we can confirm. On 2 October 2026 the game description, the Meow Labs group description, the group shout and the official event listing contained no code, and the game's social links could not be read without a Roblox login. So this page lists zero codes and shows where we looked.

| Meow Labs group description | One word: "meow?" |

## Why not copy the codes other sites list?

Because none of them traces back to an official Meow Labs post. Several fan sites publish code lists for this game. None of the codes appears in the places above, and the developer's Discord, if there is one, needs a login we do not use for research. A page full of codes nobody checked is not worth much. When a code shows up in an official source we will add a codes page that day.

## Is there an official Discord?

We could not confirm one. The social-links request returns 401 ("Authentication token is missing") without a Roblox login, so we could not read the links. Roblox's documentation adds that social media links "are only visible to users who have verified their age as at least 16 years old". The group description holds a single word, "meow?". Unless you can see a link on the game's own Roblox page, treat any "official" invite with care, and never type your Roblox password anywhere except roblox.com.

## Can you play on a private server?

We could not confirm it. The public listing gives 10 players per server, but its private-server field is unreliable, so open the Servers tab on the game page to see whether a private server option exists. Start times for the ADMIN ABUSE + WORLD 5 event are on the [updates page](/stone-skipping/updates/).

## Is the game suitable for younger players?

Roblox rates the experience "Maturity: Minimal" with the descriptor "Suitable for everyone". That label describes the content of the experience; it does not tell you how much a player could spend. +1 Stone Skipping sells 11 game passes and 78 developer products, and single items go up to 1,995 Robux, so it is worth agreeing a budget before a child plays. Every price is in the [Robux shop guides](/stone-skipping/robux/).

## How can you make sure you are in the real game?

Check three things on the game page before you spend Robux:

1. The creator is the group Meow Labs.
2. The title is +1 Stone Skipping. The description's first line calls it "+1 Skipping Stones"; both spellings are the developer's own.
3. The icon matches the one below, which currently carries a "WORLD 4" banner.

The real experience is universe 10765298801, with root place 111543903102439. Meow Labs has one public game, so a second "Stone Skipping" under another creator is not theirs.
