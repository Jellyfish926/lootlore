Beast of Reincarnation 予約特典は発売後も入手できる?

予約期間は終了しましたが、「もう特典は手に入らないのか」への答えはほぼ「入手できる」です。予約特典DLC自体は販売終了した一方、その中身はすべて 9.99 ドルのデラックスDLC に含まれており、こちらは現在も購入できます。デジタルデラックスの全内容、PS5 パッケージ版の永久封入特典、店舗別グッズ特典を整理しました。

予約特典の内容と、現在の入手可否

デジタル版の予約特典は、エディションを問わず以下の 2 点でした。外観スキンとゲーム内通貨だけで、専用武器もクエストもステータス系アイテムも含まれていません。

特典内容
クゥのスキン「茶柴犬」相棒クゥの見た目を茶色の柴犬に変更できる外観スキン。性能への影響はありません。
琥珀(アンバー)×30,000ゲーム内通貨。序盤の装備・素材調達がわずかに楽になる程度の額で、バランスを壊すものではありません。

現在の状況:2026年8月13日 時点で、Steam の「Beast of Reincarnation Pre-Order DLC」のページには購入ボタンも価格も表示されていません。予約特典DLCとしては入手できない状態です。予約済みの方のライブラリには残りますが、予約しなかった場合、この入口は閉じています。

今も開いている入口:デラックスDLC(9.99 ドル)

ただし、予約特典で配布されたものはすべてデラックスDLCにも入っています。スタンダード版からのアップグレード用として 9.99 ドルで単体販売されており、こちらは現在も購入可能です。

アイテム旧・予約特典にも入っていたか
クゥのスキン「茶柴犬」入っていた(予約特典のスキンはこれ)
クゥのスキン「黒柴犬」デラックスのみ
エマの帽子「鬼の笠」デラックスのみ
エマの剣「北斗星」デラックスのみ
琥珀(アンバー)×100,000予約特典は 30,000。デラックスは 3 倍以上
作物の苗 数種デラックスのみ

つまり、予約を見送って発売後に購入した人が恒久的に失ったものは何もありません。時限だったのは「それらを無料で受け取れる」という価格面だけで、アイテム自体は有料コンテンツとして残りました。9.99 ドルを外観と通貨に払う価値があるかは好みの問題で、判断材料はエディション比較にまとめています。

名称についての注記:デラックスの剣は、日本語ストアでは「北斗星」、英語版では "Big Dipper" と表記されます。どちらも公式名称です。発売前の一部報道(当サイトも一時期含む)では「Polaris(北極星)」と呼ばれていましたが、この名称は公式のどの資料にも存在しないため、当サイトでは全ページで修正済みです。

デジタルデラックスエディションの全内容

デジタルデラックスエディションには本編に加えて、以下のボーナスコンテンツが含まれます(PlayStation Store / Xbox ストアの掲載内容)。

アイテム種類
クゥのスキン「黒柴犬」「茶柴犬」外観スキン2種
エマの帽子「鬼の笠」装備(外観・装飾)
エマの剣「北斗星」武器
琥珀(アンバー)×100,000ゲーム内通貨
作物の苗 数種育成用アイテム

デラックス特典は「ちょっとした先行スタート+着せ替え」の域を出ない構成です。ソウルライク経験者で特典自体に魅力を感じないなら、エディション比較でも書いたとおりスタンダード版で十分です。

PS5 パッケージ版:永久封入特典

国内では Happinet からPS5 パッケージ版の発売が決定しており、永久封入特典としてデジタルデラックス相当のボーナスDLCを入手できるプロダクトコードが同梱されます。「予約しないと消える初回特典」ではなく永久封入なので、発売後にゆっくり買っても特典を逃さないのがパッケージ版の利点です。国内報道は、この封入コードで「北斗星」を含むデラックス相当のアイテムが入手できると伝えています。ただし封入特典は伝統的に初回生産分のみで、重版分では姿を消すのが通例です。輸入を検討している場合も、初回生産分かどうかを確認してから購入してください。なお、コードの内容を項目単位で伝えているのは国内の報道各社で、公式掲載が確認できるのは「デラックス相当のコードが封入される」という事実までです(項目単位の内訳は未確認)。

店舗別グッズ特典(パッケージ版)

国内報道(電撃オンラインほか)では、店舗別のオリジナルグッズ特典としてオリジナルキャンバスボード、ネックストラップ、アクリルスタンドなどがラインナップされていることが確認されています。どの店舗がどのグッズかは配布状況が変動するため、予約時に各店舗の商品ページで最新の記載を確認してください。確定し次第、本ページに店舗別の一覧表を追記します。

Game Pass 勢への注意:本作は発売初日から Game Pass に対応しますが、Game Pass 版に予約特典・デラックス特典は含まれません。柴犬スキンや「鬼の笠」が欲しい場合は、デラックスDLC(9.99 ドル)を単体で購入するのが現在の入手方法です。詳しくは Game Pass 対応まとめ へ。
