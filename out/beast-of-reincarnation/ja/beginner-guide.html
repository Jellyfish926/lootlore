    Beast of Reincarnation の基本情報

    ゲームは2026年8月4日に発売され、事前情報どおりの姿でした。ポケモン以外では初となるゲームフリークの本格オリジナルアクションRPGで、西暦4026年の荒廃した日本を舞台にした、シングルプレイ専用・パリィ主体のソウルライクです。発売済みの今、確定しているベースラインを整理します。

    項目確定情報
    発売日2026年8月4日——PS5、Xbox Series X|S、PC(Steam・Microsoft Store)で配信中。PS4版・Switch版はなし。
    価格スタンダード $59.99 / デジタルデラックス $69.99。この $10 差はすべてコスメティック・アイテム・ゲーム内通貨で、ゲーム本編の中身は変わりません。
    開発・販売ゲームフリーク(ポケモンのスタジオにとってポケモン以外で初の AAA アクションRPG)開発、Fictions, Inc. 販売。Unreal Engine 5 製。
    ジャンルパリィ最優先のソウルライク・アクションRPG——弾きのリズムは『SEKIRO』に近い手触り。
    プレイ人数シングルプレイ専用。協力プレイやマルチプレイの類は一切ありません。
    Game PassXbox Game Pass と PC Game Pass に発売初日から対応。PS5 に同種のサブスクはありません。
    ボリュームメインストーリーで約30時間、寄り道込みで約40時間、フルコンプはおよそ80時間(いずれも目安)。レベル上限は100で、実績・トロフィーの完全解除には New Game Plus が必要。
    評価OpenCritic 76(「Strong」)、41本のレビューで批評家の68%が推奨。批評家は好意的寄り、プレイヤーの評価はより割れています。戦闘は満場一致の見どころ。

    1. 戦闘の基礎——ゲームの本質はパリィにある

    エマは刀・弓・クロスボウで戦いますが、システムの心臓は弾き(ディフレクション)です。完璧なブロックは回避に勝る——ほぼ常にそうで、本作は『SEKIRO』の呼吸で作られており、正確なタイミングで攻撃を正面から受け止めることが、敵の大半の連撃に対する“想定解”です。回避も存在し使いどころもありますが、ローリングで避けて反撃するゲームとして遊ぼうとすると、手札の半分を封じたまま戦うことになります。何よりもまずこれを体に叩き込んでください——攻めるために、防ぐ。

    序盤に出会う基本的な Malefact(穢れに蝕まれた獣)は、すべて無料のパリィ講習だと思ってください。雑魚相手に磨いたタイミングは、そのままあらゆるボス戦で支払うタイミングそのもの。序盤の練習に無駄なものは一つもありません。

    2. FP とクゥの Bloom Arts——防御が攻撃を生む

    パリィが「格好いいから」ではなく必須である理由がこれです。きれいな弾きを決めるたびに FP(Florescence Points) が貯まり、この FP がクゥの Bloom Arts——相棒犬に出す強力な指示——の燃料になります。パリィをサボればプールは空のまま、空のままではクゥの最強の手が一度も発動しません。パリィで FP を稼ぎ、FP を Bloom Arts に使い、また稼ぐ——本作はこのループを軸に設計されています。

    この情報は製品版で確定済みです——検証済みの詳細は最新の英語版ページをご覧ください。

    3. Down Gauge を溜めて敵の隙をこじ開ける

    攻撃を当て、パリィを成功させると Down Gauge が溜まります。満タンにすれば、格下の Malefact はその場で処刑でき、ボスなら体勢を崩して大ダメージの窓を開けます。これこそ、弾きをうまく回すことの攻撃面での見返りです。積極的で正確なパリィは生存に役立つだけでなく、敵を「崩れた状態」へと追い込みます——戦いが実際に決着するのはこの状態です。ボスがやたら硬く感じるなら、まず間違いなく Down Gauge を使い切れていません。

    4. Entanglement Overdrive——緊急回避と反撃を兼ねる切り札

    エマには別枠の Entanglement Gauge があり、7層ぶんまで溜まります。これを解放すると Entanglement Overdrive——世界がゆっくり動くスロー状態に入り、その間に連撃を叩き込めます。5段階まで強化でき、Strength の値に紐づくため、Strength に振るほど Overdrive の威力も上がります。ボスのフェーズ移行時や、戦況が傾いた瞬間に取っておきましょう——緊急脱出口であり、同時にバースト火力の窓でもあります。

    6. 武器と3つのステータス

    装備まわりはこのジャンルにしては簡素で、序盤の判断がしやすくなっています。武器タイプはきっかり3種類:

    • 刀(Katana)——近接武器。別の刀に持ち替えでき、属性を帯びます。
    • 弓(Bow)とクロスボウ(Crossbow)——遠距離用。矢とボルトには最大3枠の属性スロットを差せます。

    属性は Fire(着火し、その後に爆発)、Lightning(Shock を付与)、Wet の3種。どの敵がどの属性に弱いかを覚えることは、本作の立派な攻略要素です——たとえば最初のボスは Fire に弱い。

    キャラクター育成はわずか3ステータスで回るので、悩ましい巨大なステ振り画面はありません:

    • Strength——攻撃と防御の両方を上げる(そして Entanglement Overdrive を強化)。
    • Vitality——HP を上げる。
    • Florescence——HP とスキル威力を上げる。

    ここから、大きく4つのプレイスタイルが立ち上がります——近接での圧力、遠距離の属性、ステルスからの処刑、そして Bloom Arts に寄せたクゥ主体のパリィ型。4つとも成立し、どこで枝分かれするかはビルド攻略で解説します。序盤で最も効く習慣は、方向を一つ決め、それを支える装備効果の周りにスキルポイントを集中させること。あれもこれもと薄く広げないことです。

    7. Cleansing Walker と強くなる仕組み

    拠点となるのが Cleansing Walker——遠征の合間にセーブと強化を行う本拠地です。ここでの成長は、初日から把握しておきたい3本の並行トラックで進みます:

    • SP は2系統のスキルツリーを伸ばします——エマ専用の系統と、クゥが伸びる別系統。
    • Spirit Stones は防具のソケットに差してパッシブ効果を得るもので、本作でいちばんジェムやルーンに近い仕組みです。
    • Nushi Skills は目玉の解放要素です。メインボスを倒すと、そのボスから吸収した新たな固有能力がエマに与えられます——だからこそボスの順番と事前準備が、通常のソウルライク以上に重みを持ちます。

    ビルドは振り直せるので、序盤のスキルポイントのミスは取り返しがつきます——遠慮なく試しましょう。そしてフルコンプには New Game Plus が必要なので、最初の周回で終わりではありません。

    9. 最初の数時間の優先事項

    1. まずパリィ、ほかは二の次。序盤エリアは雑魚相手に弾きのタイミングを叩き込む時間に。それが以降ずっと使い続ける“通貨”になります。
    2. FP はクゥに使い続ける。プールはパリィで補充されます。死んだ瞬間に FP バーが満タンなら、それは丸ごと無駄。
    3. 方向を決めてスキルポイントをシナジーに。4つに手を出すのではなく、選んだスタイルを補強する装備効果の周りに SP を集中させましょう。
    4. 属性を早めに覚える。Fire、Lightning(Shock)、Wet にはそれぞれ出番があります——Rangifer 一体だけでも、なぜ Fire が大事かを教えてくれます。
    5. クゥを大切に。撫でると Rapport が上がり、それに伴って戦闘力も上がります。単なる演出ではありません。
    6. 遠征の合間は Cleansing Walker で。セーブし、SP を振り、Spirit Stones を差し、次の地域へ進む前に態勢を立て直しましょう。

    10. やりがちなミス

    • FP を溜め込む。プールは「使って補充する」前提で設計されています。抱え込むのは、手札の半分を暗いまま戦うのと同じ。
    • ローリング偏重のソウルライクとして遊ぶ。想定された防御は回避ではなく弾きです。何でも転がって避けると、Down Gauge——そして最大火力——を取りこぼします。
    • コマンドメニューに“住む”(または存在を忘れる)。時間はスローになりますが停止はしません。弾きのフレーズの合間に打つ句読点として使い、隠れ家にしないこと。
    • スキルポイントを薄く広げる。4スタイルとも成立しますが、散らかしたビルドが詰まる壁を、絞ったビルドは抜けていきます。あとで振り直せるので、いまは決め打ちを。
    • Game Pass を確認せずに Xbox / PC で買う。Xbox Game Pass か PC Game Pass に加入済みなら、発売初日から追加費用なしで遊べます。PS5 勢にこの選択肢はないので、代わりにエディションを比較しましょう。
    • チェックリストの先に“真の”second ending を期待する。本作はメインストーリーのエンディングが一つあり、その先に New Game Plus が続きます。存在しない仕掛けを追いかけないこと。

    パフォーマンスについて

    インストール前に知っておきたいことが2つ。PC 版は SSD が必須、RAM は最低16GB を要求し、DLSS/FSR のアップスケーリングに対応、容量はおよそ45GB です。PS5 版のパフォーマンスモードは60fps を狙いますが、ボス戦ではフレームが落ち、一部に低解像度テクスチャが混じります。Steam Deck は発売時点で Verified ではありません——ここで遊ぶなら、Low 設定で40fps に固定するのが現実的な出発点です。ボス戦のカメラと、PC/Steam Deck のパフォーマンスは、発売時レビューで最も多い2大不満なので、その前提で期待値を調整してください。詳しくはパフォーマンス攻略とPC要件のページへ。

    初心者 FAQ

    もう発売してる?いちばん安く試す方法は?

    はい、2026年8月4日に発売済みです。Xbox と PC では Xbox Game Pass または PC Game Pass に発売初日から含まれており、これが最も安く試す方法です。PS5 にはサブスクの選択肢がないため、こちらは単体購入になります。

    『SEKIRO』などのソウルライクを先にやっておく必要は?

    ありません。『SEKIRO』との比較はパリィ中心のリズムを指すものであって、参入障壁の話ではありません。大事なのは回避より弾きに徹すること、そして FP をクゥに流し続けること。この2つの習慣は、ジャンル経験よりずっと遠くへ連れて行ってくれます。

    スタンダードとデラックスの違いは?

    $69.99 のデジタルデラックスは、$59.99 のスタンダードに加えて、クゥの黒・茶のスキン、エマの「Oni's Hat」、「Big Dipper」という名の剣、琥珀100,000、作物の種苗が付きます。どれもコスメティックかアイテムか通貨で、$10 の差がゲーム本編の中身を左右することは一切ありません。

    クリアまでどれくらい?エンドロールの先はある?

    メインストーリーで約30時間、寄り道込みで約40時間、フルコンプでおよそ80時間(いずれも目安)。メインストーリーのエンディングは一つで、その先に New Game Plus が続きます——実績・トロフィーの完全解除にはこれが必要なので、最初の周回で終わりではありません。

    失敗したビルドは直せる?

    直せます。ビルドは振り直せて、レベル上限は100なので、序盤のスキルポイントの選択は固定されません。4つのプレイスタイルを遠慮なく試しましょう。

    PC ではコントローラーとキーボード、どちらがいい?

    Steam でも Microsoft Store でも両対応です。弾きのタイミングが要のゲームなので、無難なのはコントローラーですが、どちらでも遊べます。
