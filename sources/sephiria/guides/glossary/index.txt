3:T3049,<p>This wiki uses proper nouns Sephiria itself never explains in one place — a tablet family, a currency, a community tool. Every definition below already appears on a longer page on this site; this is the index that lets you look one term up without re-reading the whole guide it came from.</p>

<h2>A</h2>
<p><strong>Adaptive (Carrot)</strong> — the Fruit Skewer modifier with the highest ceiling, up to +75% drop bonus. See <a href="/guides/run-events/">run events</a>.</p>
<p><strong>Anvil</strong> — the room type where <a href="/weapons/all-weapons/">weapon</a> upgrades happen. Gated by stage progress, so the standing advice is to rush every one.</p>
<p><strong>Ark</strong> — location of the puzzle unlocking the Willpower talent tree via <strong>Terrain Recovery</strong>. See <a href="/guides/destiny-inscription/">Destiny Inscription</a>.</p>
<p><strong>Artifact</strong> — the primary build item, roughly 300 by TEAM HORAY's count. Sits in the <a href="/guides/inventory-grid/">inventory grid</a>; a <a href="/tablets/all-tablets/">tablet</a> decides how much of it fires. Full page: <a href="/artifacts/artifacts-and-tablets/">artifacts and tablets</a>.</p>
<h2>B</h2>
<p><strong>Battle Wave</strong> — a combat room with a <em>chance</em> of a bonus reward on clear (patch 0.7.32). See <a href="/guides/run-events/">run events</a>.</p>
<p><strong>Blood Donation</strong> — pay 33% current HP to the Iron Maiden for an item; killing the room's vampire bat instead grants Oath of the Vampire Lord but locks the Maiden. See the <a href="/guides/beginner/">beginner guide</a>.</p>
<p><strong>Bond Artifact</strong> — a unique artifact connecting two <a href="/guides/combo-effects/">combo</a> tags at once; drops once <em>either</em> linked combo is active.</p>
<p><strong>Bunnyville</strong> — the hub village between runs.</p>
<h2>C</h2>
<p><strong>Chalcedony Key</strong> — an artifact that changes its own combo tag by grid position — a free threshold-filler. See <a href="/guides/combo-effects/">combo effects</a>.</p>
<p><strong>Chaos Damage</strong> — since the October 2025 revamp, an attribute that counts as <strong>all four</strong> of Fire, Ice, Lightning and Physical at once. See <a href="/guides/damage-types/">damage types</a>.</p>
<p><strong>Chest of Possibilities</strong> — spend Sapphires to restock a merchant; reroll cost doubles 2 → 4 → 8 → 16.</p>
<p><strong>Colin / Collin</strong> — the mercenary NPC who sells a #Companion token for 500 Leaf. Patch notes spell it both ways; this wiki prints both. See the <a href="/bosses/boss-room-preparation-checklist/">boss preparation checklist</a>.</p>
<p><strong>Combo</strong> — a bonus activated by holding enough same-tagged <a href="/artifacts/artifacts-and-tablets/">artifacts</a>, counted anywhere in the bag. Not the same as grid combination, below. Full page: <a href="/guides/combo-effects/">combo effects</a>.</p>
<p><strong>Comprehensive Training Grounds</strong> — added in 0.11.5, a village facility for testing a weapon's full upgrade tree without spending a run.</p>
<p><strong>Curse</strong> — the one board-parity <a href="/tablets/all-tablets/">tablet</a>, from the Skeleton <a href="/guides/costumes/">costume</a>: +1 to odd grid cells, −1 to even ones, whole board, rotation does nothing.</p>
<h2>D</h2>
<p><strong>DEF (enemy Defense)</strong> — a stat enemies gain as stages progress. See <a href="/guides/damage-types/">damage types</a> and the per-floor table on <a href="/bosses/chapters-and-bosses/">chapters and bosses</a>.</p>
<p><strong>Derangement</strong> — a node-risk modifier meaning enemies on that node are randomly enhanced. See the <a href="/guides/beginner/">beginner guide</a>.</p>
<p><strong>Destiny Inscription</strong> — the meta-progression tree; full completion costs 383 Sapphires across 12 tiers. Full page: <a href="/guides/destiny-inscription/">Destiny Inscription</a>.</p>
<p><strong>Dice</strong> — spent to reroll offers; up to 6 starting dice via Destiny Inscription.</p>
<p><strong>Dimensional Rift</strong> — spend Sapphires to permanently unlock artifacts into your pool; 8 artifacts and 1 tablet exist only here.</p>
<h2>E</h2>
<p><strong>Edge-anchored tablet</strong> — one of four tablets (Good Will, Shade, Flag, Justice) inactive off a specific grid edge. See <a href="/tablets/all-tablets/">tablet families</a>.</p>
<p><strong>Electrocute</strong> — a debuff dealing 180% lightning damage after a 2-second delay, stacking twice without refreshing. See <a href="/guides/damage-types/">damage types</a>.</p>
<p><strong>Enchantment</strong> — a node altar that raises an <em>artifact's</em> level directly (1–3 uses). A property of the artifact, unlike a tablet buff, which stays with the cell. See <a href="/guides/inventory-grid/">inventory grid</a>.</p>
<p><strong>Execute</strong> — since October 2025, doubles your own critical-hit damage multiplier and counts as a crit, replacing a flat 400% that ignored crit status. See <a href="/guides/damage-types/">damage types</a>.</p>
<h2>F</h2>
<p><strong>Focus</strong> — one of the Dagger's three resource meters, with Fury and Trance. See the <a href="/weapons/dagger-guide/">Dagger guide</a>.</p>
<p><strong>Foundation</strong> — a line <a href="/tablets/all-tablets/">tablet</a> buffing its whole row +1; <a href="/guides/talents/">Endure</a> grants one free at run start.</p>
<p><strong>Fruit Skewer</strong> — biases which combo tags' items appear, set before a run. See <a href="/guides/run-events/">run events</a>.</p>
<p><strong>Fury</strong> — the Dagger meter that turns Parry into a damage tool. See the <a href="/weapons/dagger-guide/">Dagger guide</a>.</p>
<h2>G</h2>
<p><strong>Green Heart</strong> — a node worth +15 Max HP. See the <a href="/guides/beginner/">beginner guide</a>.</p>
<p><strong>Grid combination</strong> — the geometric system where <a href="/tablets/all-tablets/">tablets</a> project buffs onto specific cells, summed per cell. Combo's counting-based sibling; frequently confused with it. See <a href="/guides/combo-effects/">combo effects</a>.</p>
<h2>H</h2>
<p><strong>Hard Mode (Root's Retreat)</strong> — post-completion difficulty, tiers 1–60; clearing a tier pays one talent point on schedule, one reward tier claimable per clear. Full page: <a href="/guides/hard-mode/">Hard Mode</a>.</p>
<h2>I</h2>
<p><strong>Ingenuity</strong> — the talent tree whose level-20 capstone grants +7% universal damage per active combo type. See <a href="/guides/talents/">talents</a>.</p>
<p><strong>Iron Maiden</strong> — the device in the Blood Donation event; see <strong>Blood Donation</strong> above.</p>
<h2>J</h2>
<p><strong>Journal</strong> — the in-game menu (Esc → Journal) showing every seen artifact and every weapon's full upgrade path.</p>
<h2>L</h2>
<p><strong>Leaf</strong> — the in-run currency.</p>
<p><strong>Line tablet</strong> — a family buffing an entire row, column or diagonal; twelve exist, Requital (+3 to its row) strongest.</p>
<h2>M</h2>
<p><strong>Mini-boss</strong> — an enhanced enemy on grey-skull nodes, always drops an artifact. Roster on <a href="/bosses/chapters-and-bosses/">chapters and bosses</a>.</p>
<p><strong>Miracle</strong> — a once-per-run Tree Roots reward; several grant a starting item.</p>
<p><strong>Mystic (combo)</strong> — doubles the <em>net</em> value of up to three chosen grid cells per current tooling — though TEAM HORAY's own text says a <em>random</em> artifact, never publicly reconciled. See <a href="/guides/inventory-grid/">inventory grid</a>.</p>
<p><strong>Mystic Pot</strong> — converts 1 artifact into another of the same rarity, or 2 into one of higher rarity. See <a href="/artifacts/artifacts-and-tablets/">artifacts and tablets</a>.</p>
<h2>N</h2>
<p><strong>Node</strong> — a floor's route choice: reward type on top, risk on bottom. See the <a href="/guides/beginner/">beginner guide</a>.</p>
<h2>O</h2>
<p><strong>Obelisk</strong> — a run event; in Chapter 6 it shows a lore sequence instead of its usual buff. See <a href="/guides/chapter-walkthrough/">chapter walkthrough</a>.</p>
<h2>P</h2>
<p><strong>Parity tablet</strong> — see <strong>Curse</strong> above; the only tablet in this family.</p>
<p><strong>Pocket Dimension</strong> — a shop event with the blank-description achievement <em>Where the Blue Being Lives</em> (77.2%). See <a href="/guides/run-events/">run events</a>.</p>
<p><strong>Preset</strong> — a saved loadout; slot count rose from 7 to 15 with locking in patch 1.0.26.</p>
<h2>Q</h2>
<p><strong>Qliphoth</strong> — the three-form final boss, floor 7, Chapter 6. See <a href="/bosses/final-boss-and-endings/">final boss and endings</a>.</p>
<h2>R</h2>
<p><strong>Root's Retreat</strong> — internal name for Hard Mode; see above.</p>
<h2>S</h2>
<p><strong>Sapphire</strong> — meta-progression currency, earned on death, spent in Destiny Inscription.</p>
<p><strong>SephiriaSolver</strong> — a free community tool that searches for optimal tablet layouts. See <a href="/tablets/tablet-solver-and-placement/">tablet solver and placement</a>.</p>
<p><strong>Side Bag</strong> — added in 1.0; <strong>items in it are inactive</strong> and do not count toward combos. See <a href="/guides/inventory-grid/">inventory grid</a>.</p>
<h2>T</h2>
<p><strong>Tablet</strong> — the item projecting buff values onto grid cells, deciding an artifact's effective level. About 70 by TEAM HORAY's count. Full page: <a href="/tablets/all-tablets/">tablet families</a>.</p>
<p><strong>Tablet Combiner</strong> — merges two tablets into one, added 0.10.14. See <a href="/tablets/all-tablets/">tablet families</a>.</p>
<p><strong>Talent</strong> — one of seven free-respec trees, funded by 25 Destiny Inscription points plus 20 from Hard Mode. Full page: <a href="/guides/talents/">talents</a>.</p>
<p><strong>Tension</strong> — a Hard Mode modifier disabling potions during boss fights. See <a href="/guides/hard-mode/">Hard Mode</a>.</p>
<p><strong>Trance</strong> — a Dagger resource state, stacking up to 4 times at the current upgrade tier. See the <a href="/weapons/dagger-guide/">Dagger guide</a>.</p>
<p><strong>Transference</strong> — the panel for changing an artifact's level or rotation on its cell. See <a href="/guides/inventory-grid/">inventory grid</a>.</p>
<h2>V</h2>
<p><strong>Void Damage</strong> — replaced "unclassified" damage after the October 2025 revamp: corresponds to <em>none</em> of Fire, Ice, Lightning or Physical. See <a href="/guides/damage-types/">damage types</a>.</p>
<h2>W</h2>
<p><strong>Wandering Witch</strong> — a rare shop event; 11 artifacts and 2 tablets exist only there.</p>
<p><strong>Wish Fountain</strong> — carries chosen items into a run; base capacity 4, extended by Willpower (whose exact maximum the official record contradicts). Full page: <a href="/artifacts/wish-fountain-carry-in-artifacts/">Wish Fountain</a>.</p>
<h2>Numbers and symbols</h2>
<p><strong>[Unique] Stacking</strong> — what Wisdom talent level 10 actually grants: duplicates get offered, taking one adds a star to the copy you hold — not the "+2 combo" shorthand that circulates elsewhere. See <a href="/guides/talents/">talents</a>.</p>
<p><strong>×2 Slot</strong> — the <a href="/tablets/tablet-solver-and-placement/">SephiriaSolver</a> marking for cells doubled by the Mystic combo; up to three since tool v2.0.</p>
