Beast of Reincarnation は Game Pass で遊べる?

結論:遊べます。発売初日(2026年8月4日)から Game Pass 対応です。追加購入なしでプレイでき、Play Anywhere により Xbox と PC の両方でセーブデータを共有して遊べます。

公式発表・ストア掲載情報に基づく(2026年8月13日 再確認)。Ultimate ではクラウドストリーミングにも対応

対応状況の早見表

項目状況
Game Pass 初日対応対応(2026年8月4日の発売日から配信)
対象プランGame Pass Ultimate と PC Game Pass の 2 プランのみ(ストア掲載で確認済み・2026年8月13日)。Premium / Essential は対象外で、これらのプランでは購入済みの自分のゲームとしてしかストリーミングできません
Play Anywhere対応。Xbox Series X|S と Windows PC の両方で追加費用なしでプレイでき、セーブデータ・実績も共有
PS5 版Game Pass の対象外(PS5 では通常購入のみ・¥8,980 税込)

買い切りと Game Pass、どちらが得か

判断基準はシンプルです。

  • すでに Game Pass Ultimate に加入している → 迷う理由がありません。発売日にそのままプレイするのが最安です。クリア時間の目安を見ても、1〜2 か月の加入期間内に本編を遊び切れる程度のボリュームです。
  • 未加入で、本作だけが目当て → クリアまで遊んで手元に残したいなら買い切り(¥8,980)、まず合うかどうか確かめたいなら 1 か月だけ加入して試すのが合理的です。パリィ主体の高難度アクションなので、難易度まとめを先に読んでおくことをおすすめします。
  • PS5 でしか遊ばない → Game Pass という選択肢自体がないため、エディション比較でスタンダードかデラックスかだけ決めれば OK です。

Game Pass 版の注意点:特典 DLC は含まれない

Game Pass で遊ぶ場合、予約特典・デジタルデラックス特典(クゥの柴犬スキン、鬼の帽子、剣「北斗星」、琥珀ボーナスなど)は含まれません。特典アイテムが欲しい場合は、発売後に単体販売が始まったデラックス DLC(Steam で $9.99・2026年8月13日確認)を購入する方法があります。予約特典だった茶柴犬スキンと琥珀も、このデラックス DLC に(琥珀は 100,000 に増量されて)含まれています。詳しくは特典まとめへ。

体験版代わりにもなる:本作には現時点で体験版がないため、「まず触ってみたい」人にとって Game Pass は実質的な試遊手段でもあります。詳しくは体験版まとめへ。
