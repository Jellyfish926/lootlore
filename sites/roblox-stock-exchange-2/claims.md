读表说明:
- **原句**以 `tldr:` / `faq:` / `alt <key>:` / `caption <key>:` 开头的,出自该页 frontmatter 或图片 alt / 图注,其余出自正文。表格行以 `| … |` 形式给出。
- **等级**:S = Roblox 官方接口 / 官方文档 / 官方上传的宣传图与活动配图;`S (derived)` = 用 S 级数字做的算术(摘录里给出算式);B = Discord 服务器自述、Google 下拉;C = 第三方码站 / 小 wiki(只用于「别站怎么说」这类命题,不支撑任何游戏事实)。本批 A 级 0 条。
- **图片类命题**(source_url 为 tr.rbxcdn.com):摘录是本人看图抄下的图中文字,验证员需打开图片核对;这些图是更新前的宣传图,页面上均以 the art shows 口径出现。
- **(negative claim)**:「官方来源里没有某内容」类命题,需验证员通读对应来源确认。
- 取数时刻:games / votes / group = 2026-10-08 03:39 UTC;badges = 03:47 UTC;其余 03:39–04:10 UTC。快照数字会随时间增长,复核时以 raw/ 存档为准,线上重取会略大。
