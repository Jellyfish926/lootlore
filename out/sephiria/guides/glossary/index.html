Sephiria Glossary: Every Term, One Page, A to Z

By Jellyfi · Published 2026-09-11 · Last reviewed 2026-09-11 · Game version checked 1.0.30

This wiki uses proper nouns Sephiria itself never explains in one place — a tablet family, a currency, a community tool. Every definition below already appears on a longer page on this site; this is the index that lets you look one term up without re-reading the whole guide it came from.

A

Adaptive (Carrot) — the Fruit Skewer modifier with the highest ceiling, up to +75% drop bonus. See run events.

Anvil — the room type where weapon upgrades happen. Gated by stage progress, so the standing advice is to rush every one.

Ark — location of the puzzle unlocking the Willpower talent tree via Terrain Recovery. See Destiny Inscription.

Artifact — the primary build item, roughly 300 by TEAM HORAY's count. Sits in the inventory grid; a tablet decides how much of it fires. Full page: artifacts and tablets.

B

Battle Wave — a combat room with a chance of a bonus reward on clear (patch 0.7.32). See run events.

Blood Donation — pay 33% current HP to the Iron Maiden for an item; killing the room's vampire bat instead grants Oath of the Vampire Lord but locks the Maiden. See the beginner guide.

Bond Artifact — a unique artifact connecting two combo tags at once; drops once either linked combo is active.

Bunnyville — the hub village between runs.

C

Chalcedony Key — an artifact that changes its own combo tag by grid position — a free threshold-filler. See combo effects.

Chaos Damage — since the October 2025 revamp, an attribute that counts as all four of Fire, Ice, Lightning and Physical at once. See damage types.

Chest of Possibilities — spend Sapphires to restock a merchant; reroll cost doubles 2 → 4 → 8 → 16.

Colin / Collin — the mercenary NPC who sells a #Companion token for 500 Leaf. Patch notes spell it both ways; this wiki prints both. See the boss preparation checklist.

Combo — a bonus activated by holding enough same-tagged artifacts, counted anywhere in the bag. Not the same as grid combination, below. Full page: combo effects.

Comprehensive Training Grounds — added in 0.11.5, a village facility for testing a weapon's full upgrade tree without spending a run.

Curse — the one board-parity tablet, from the Skeleton costume: +1 to odd grid cells, −1 to even ones, whole board, rotation does nothing.

D

DEF (enemy Defense) — a stat enemies gain as stages progress. See damage types and the per-floor table on chapters and bosses.

Derangement — a node-risk modifier meaning enemies on that node are randomly enhanced. See the beginner guide.

Destiny Inscription — the meta-progression tree; full completion costs 383 Sapphires across 12 tiers. Full page: Destiny Inscription.

Dice — spent to reroll offers; up to 6 starting dice via Destiny Inscription.

Dimensional Rift — spend Sapphires to permanently unlock artifacts into your pool; 8 artifacts and 1 tablet exist only here.

E

Edge-anchored tablet — one of four tablets (Good Will, Shade, Flag, Justice) inactive off a specific grid edge. See tablet families.

Electrocute — a debuff dealing 180% lightning damage after a 2-second delay, stacking twice without refreshing. See damage types.

Enchantment — a node altar that raises an artifact's level directly (1–3 uses). A property of the artifact, unlike a tablet buff, which stays with the cell. See inventory grid.

Execute — since October 2025, doubles your own critical-hit damage multiplier and counts as a crit, replacing a flat 400% that ignored crit status. See damage types.

F

Focus — one of the Dagger's three resource meters, with Fury and Trance. See the Dagger guide.

Foundation — a line tablet buffing its whole row +1; Endure grants one free at run start.

Fruit Skewer — biases which combo tags' items appear, set before a run. See run events.

Fury — the Dagger meter that turns Parry into a damage tool. See the Dagger guide.

G

Green Heart — a node worth +15 Max HP. See the beginner guide.

Grid combination — the geometric system where tablets project buffs onto specific cells, summed per cell. Combo's counting-based sibling; frequently confused with it. See combo effects.

H

Hard Mode (Root's Retreat) — post-completion difficulty, tiers 1–60; clearing a tier pays one talent point on schedule, one reward tier claimable per clear. Full page: Hard Mode.

I

Ingenuity — the talent tree whose level-20 capstone grants +7% universal damage per active combo type. See talents.

Iron Maiden — the device in the Blood Donation event; see Blood Donation above.

J

Journal — the in-game menu (Esc → Journal) showing every seen artifact and every weapon's full upgrade path.

L

Leaf — the in-run currency.

Line tablet — a family buffing an entire row, column or diagonal; twelve exist, Requital (+3 to its row) strongest.

M

Mini-boss — an enhanced enemy on grey-skull nodes, always drops an artifact. Roster on chapters and bosses.

Miracle — a once-per-run Tree Roots reward; several grant a starting item.

Mystic (combo) — doubles the net value of up to three chosen grid cells per current tooling — though TEAM HORAY's own text says a random artifact, never publicly reconciled. See inventory grid.

Mystic Pot — converts 1 artifact into another of the same rarity, or 2 into one of higher rarity. See artifacts and tablets.

N

Node — a floor's route choice: reward type on top, risk on bottom. See the beginner guide.

O

Obelisk — a run event; in Chapter 6 it shows a lore sequence instead of its usual buff. See chapter walkthrough.

P

Parity tablet — see Curse above; the only tablet in this family.

Pocket Dimension — a shop event with the blank-description achievement Where the Blue Being Lives (77.2%). See run events.

Preset — a saved loadout; slot count rose from 7 to 15 with locking in patch 1.0.26.

Q

Qliphoth — the three-form final boss, floor 7, Chapter 6. See final boss and endings.

R

Root's Retreat — internal name for Hard Mode; see above.

S

Sapphire — meta-progression currency, earned on death, spent in Destiny Inscription.

SephiriaSolver — a free community tool that searches for optimal tablet layouts. See tablet solver and placement.

Side Bag — added in 1.0; items in it are inactive and do not count toward combos. See inventory grid.

T

Tablet — the item projecting buff values onto grid cells, deciding an artifact's effective level. About 70 by TEAM HORAY's count. Full page: tablet families.

Tablet Combiner — merges two tablets into one, added 0.10.14. See tablet families.

Talent — one of seven free-respec trees, funded by 25 Destiny Inscription points plus 20 from Hard Mode. Full page: talents.

Tension — a Hard Mode modifier disabling potions during boss fights. See Hard Mode.

Trance — a Dagger resource state, stacking up to 4 times at the current upgrade tier. See the Dagger guide.

Transference — the panel for changing an artifact's level or rotation on its cell. See inventory grid.

V

Void Damage — replaced "unclassified" damage after the October 2025 revamp: corresponds to none of Fire, Ice, Lightning or Physical. See damage types.

W

Wandering Witch — a rare shop event; 11 artifacts and 2 tablets exist only there.

Wish Fountain — carries chosen items into a run; base capacity 4, extended by Willpower (whose exact maximum the official record contradicts). Full page: Wish Fountain.

Numbers and symbols

[Unique] Stacking — what Wisdom talent level 10 actually grants: duplicates get offered, taking one adds a star to the copy you hold — not the "+2 combo" shorthand that circulates elsewhere. See talents.

×2 Slot — the SephiriaSolver marking for cells doubled by the Mystic combo; up to three since tool v2.0.

How this page was built

Every definition above compresses a longer explanation already on this wiki — no new claims are made here, and nothing is sourced outside the site's own pages.
