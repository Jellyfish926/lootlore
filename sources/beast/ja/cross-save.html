Beast of Reincarnation のセーブデータは機種間で共有できる?

確定しているのは Xbox Series X|S ⇄ Windows PC 間の Play Anywhere 対応(セーブデータ・実績を共有)。それ以外の組み合わせは現時点で公式発表がありません。機種選びの前に知っておきたい現状を整理します。

公式発表・ストア掲載情報に基づく・発売後に実機検証で更新予定

組み合わせ別の対応状況

組み合わせセーブ共有備考
Xbox ⇄ PC(Microsoft ストア / Game Pass)対応Play Anywhere 対応タイトル。1 回の購入(または Game Pass 加入)で両方遊べて、セーブデータと実績が自動同期
PS5 ⇄ PC発表なし公式からのアナウンスは現時点でありません
Steam ⇄ Xbox / PS5発表なしストア間のセーブ移行は未発表。前例的にも期待薄
同一機種内のクラウドセーブ各社の標準機能に準拠PS Plus のセーブお預かり、Xbox のクラウドセーブ、Steam Cloud の対応可否は発売時にストア表記を確認して追記します

機種選びへの実践的な影響

  • 据置とノート PC の両方で遊びたい → 現状の最適解は Xbox / Microsoft ストア版(または Game Pass)。Play Anywhere により追加費用なしで行き来できます。詳しくは Game Pass 対応まとめへ。
  • Steam 版を選ぶ場合 → 他機種への持ち出しは想定しない方が安全です。PC 環境の要件は必要スペックまとめを確認してください。
  • PS5 版を選ぶ場合 → セーブは PS5 内(+PS Plus クラウド)で完結する前提で考えるのが現状は無難です。

クロスプレイとの違い

クロスセーブは「自分のセーブデータを別の機種に持っていけるか」、クロスプレイは「別の機種の他人と一緒に遊べるか」です。本作は一人と一匹の旅を描くシングルプレイ主体のアクション RPG で、オンライン協力・対戦の有無についてはマルチプレイ対応まとめで別途整理しています。
