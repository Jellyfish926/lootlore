Orc Problem Update History: Every Patch Since Launch

Last verified 2026-09-01

Last reviewed: 1 September 2026 · Newest update reflected: 2026.08.18.12.05 (published 19 August 2026).

Since launching on 28 July 2026, Sir, We Have an Orc Problem has received two updates, and the second one ends with the only roadmap statement Mumpitz Games has made: an in-game level editor is in the works. This page keeps the full post-launch record in one place, because the game has no version numbers in the usual sense — updates are named by timestamp, like 2026.08.18.12.05, and the Steam news hub is the only official archive.

The 18 August update: quality of life, plus one balance change

Published on 19 August 2026 under the name 2026.08.18.12.05, this patch is mostly quality of life, but the first line is a real balance change: a new upgrade that grants more Strafing Run uses. If your ability rotation leans on the aircraft, there is now a node for it — see the abilities page for what the Strafing Run baseline looks like.

The rest of the patch, as the announcement lists it:

  • A new music track that unlocks after playing level 3.2
  • Window size options, with custom sizes saved and restored automatically
  • An option to disable hit flashes
  • A credits panel
  • Increased background brightness on level 3.2
  • A battle shortcut ('H') to hide the UI
  • Sturdier savegame writing, to prevent file corruption
  • The aim preview now accounts for bullet spread and bullet size
  • Number formatting fixes

Two of those lines quietly serve one level: 3.2 got both a brightness pass and the unlockable music track. Our 3.2 difficulty spike page covers why that level filters players; the visual pass does not change its balance, just how readable the chaos is.

The announcement closes with the sentence that matters for the game's future: the developers are working on an in-game level editor, "but this will take a bit more time. Just wanted to let you know that we hear you and there will be more content in the future."

The 2 August update: the 6.1 wall got a little thinner

The first post-launch patch, 2026.08.02.13.35, published 4 August 2026, shipped four days after release and touched the game's hardest content directly. It widened a path in level 6.1 so orcs no longer get stuck — relevant to anyone chasing the four-turret-type achievement there, since stuck orcs meant runs that could neither be won nor lost cleanly. It also added an upgrade letting the Laser fire in a straight line without sway, the second balance lever in a patch otherwise made of fixes:

  • Failed Steam initialization no longer quits the game
  • A separate volume slider for missile sounds, and a bloom-strength slider for the Tech Tree view
  • Strafing Run audio made non-positional and slightly louder
  • A German localization spelling fix ("Kostenloser Durchschlag Chance")
  • Fixes for number formatting and for "Play Again" being pressable multiple times

If a turret stat sheet you are reading predates 4 August, the Laser's behaviour is the number most likely to have moved — worth remembering when comparing the community figures on our all turrets page.

What launched around the patches

The updates landed in an unusually loud first week. On 1 August, four days after release, Mumpitz Games announced 100,000 copies sold. On 4 August the Supporter Pack — a $2.99 cosmetic DLC the developers describe as a tip jar — went live alongside the first patch. The next day, GamingOnLinux ran a piece calling the game "a thoroughly satisfying mixture of incremental-style tower defense," which remains the most substantial press coverage to date.

How to read this game's update cadence

Two patches in three weeks, then quiet through the end of August — with the stated reason being editor work. The pattern from the pre-release period supports taking that at face value: between May and July 2026 the developers shipped playtest and demo updates at a steady clip and communicated each one, so silence here has so far meant "building," not "abandoned." We will add each new update to this page as it is published, with the same rule as everywhere else on this site: the announcement text is the source, and anything we could not trace to it does not appear.

What is not here

No datamined changes, no undocumented tweaks players suspect but the announcements do not mention, and no predicted release date for the level editor — Mumpitz Games has not given one, so neither do we.
