# Author: Jellyfi, Roblox Stock Exchange 2 Guide Editor

Jellyfi is the editorial byline on {{BRAND}}, responsible for researching, publishing and maintaining the [Roblox Stock Exchange 2 guides](/roblox-stock-exchange-2/) on this site. Every guide published under that byline is listed below.

## How these guides are researched

The game lives on Roblox, so the most reliable facts are the ones its developer registers there: the game description, the badge list, the game passes, the store products and the official event listings. Those are read directly from Roblox's public data and quoted word for word, with the date they were checked.

![The game's official icon: a rising arrow filled with scenes of a candlestick chart, a computer chip, solar panels, data servers and a city campus](icon "Every guide in this section is published under one editorial byline")

Official event art is treated as a second tier. It is the developer's own material, but it is made to promote an update before release, so anything taken from it is labelled as coming from the art.

Code sites, fan wikis and videos are used only as leads. If one of them is the only source for a fact, such as a code, a fee, a rebirth cost or a bot setting, that fact stays out until something official confirms it.

## How codes are handled

A code is listed only after it has been seen in an official source, and the page says whether it has been tested in the game. For this game the source has been the description on Roblox. When a code leaves that source it is marked expired and kept on the [codes page](/roblox-stock-exchange-2/codes/) with the date it was noticed.

## Why there is no trading advice here

The game borrows the language of real markets, and it would be easy to slide from explaining a mechanic into recommending a strategy. These guides do not. The developer states that all markets and currencies in the game are simulated. Suggestions such as a buying order for passes or a first-session checklist are editorial opinions about a game, and each page marks them as such.

## How to read the dates on a page

"Published" is when the page first went live. "Last checked" is when the text was compared against its sources. Roblox counters such as visits, likes and badge totals are snapshots from that day and keep growing.

## Reporting an error

Official update events have been listed about once a week since 17 August 2026. If a price, a name or a menu no longer matches what you see, use the [Contact](/contact) page and include the page link and, if you can, a screenshot. Screenshots of the code box, the rebirth screen and the bot settings are especially welcome, because those are gaps the official data does not fill. The site-wide writing and correction rules are on the [Editorial Policy](/editorial-policy) page.
