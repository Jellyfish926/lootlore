    All 11 Achievements With Steam Unlock Rates

    By Jellyfi · Last verified 2026-09-01

    Last reviewed: 1 September 2026 · Newest game update reflected: 2026.08.18.12.05 (18 August 2026). There are 11 achievements, and their official Steam names are listed below exactly as the game spells them. Three mark progress; the other eight are self-imposed constraints, and the gap between those two groups is enormous — 97.2% of players survive the first level, but only 12.1% ever clear one using exactly four turret types.

    Every percentage below is Steam's own global unlock rate, re-read on 1 September 2026. It is the only measured difficulty ranking that exists for this game.

    Prefer to tick these off as you go? The achievement tracker uses the same Steam data, refreshed weekly, and saves your progress in your browser.

    The full list, hardest last

    Against All Odds29.8%Clear the sixth level
    One Is Enough25.5%One turret, no abilities
    Specialist22.5%One turret type, no abilities

    The inversion at the bottom is not a mistake

    Using four turret types (Four-tified, 12.1%) is rarer than using three (Triple Threat, 17.1%), and rarer than using one (Specialist, 22.5%). That reads backwards until you notice what the constraint is really doing.

    These challenges forbid abilities. Once abilities are gone, difficulty comes down to whether turret placement alone can hold every lane — and the levels these are attempted on get harder as the type allowance rises. A single-turret run is done on an early level where one upgraded laser suffices. A four-type run is done on 6.1, which has multiple approach routes.

    So the number of turret types is not the difficulty. It is a proxy for which level you are being asked to do it on.

    Which level each one is done on

    The guide by itsuno, posted 29 July 2026 and read by roughly 4,900 people, lists the level used for each constraint achievement:

    • 1.1 — single turret, no abilities. itsuno used a laser with a good bounce setup, and notes a machine gunner or flamethrower also works if their upgrade levels are high enough.
    • 2.1 — no turrets. "Requires no guide" in his words; any of the four click abilities will do it.
    • 3.1 — one turret type, no abilities. High-level flamethrowers.
    • 4.1 — flamethrower, tesla coil and cryo beam only. This is the "elemental" achievement.
    • 5.1 — three turret types, no abilities.
    • 6.1 — four turret types, no abilities.

    A second guide covering the harder achievements describes 5.1 as "pretty easy" with defences set up covering the rear, and adds that the bottom two cannons and machine guns could have gone elsewhere because so few enemies reached them.

    Read these as where one player did it, not as a requirement. The game does not state that these achievements are level-locked, and we have not found a source that confirms it either way.

    Buy all is a grind, not a challenge

    At 19.5%, purchasing every upgrade — Fully Loaded — sits mid-pack, but it is the only achievement here that cannot be shortened by playing better. Mumpitz Games' store description confirms resources come from every run, won or lost, so this one is purely a function of hours played.

    If you are chasing completion, start it early and let it accumulate underneath everything else.

    The realistic order to attempt them

    Progression first — surviving levels 1, 3 and 6 happens naturally, and clearing 6 already puts you ahead of 73% of players.

    Then the nuke achievement, which needs only patience with a bunched wave. Then the no-turret run, which tests your ability upgrades rather than your skill.

    Leave the no-ability constraints for last, in the order itsuno lists them. Level difficulty rises with the type allowance, so one turret on 1.1 is genuinely easier than four types on 6.1 despite the constraint sounding tighter.

    What we have not documented

    Steam's API returns internal achievement identifiers rather than display names, and we do not have an API key configured to resolve them. The names in the table above are our plain-English readings of those identifiers, cross-checked against itsuno's descriptions — they are not the exact strings the game shows. We also do not know whether any achievement is hidden.
