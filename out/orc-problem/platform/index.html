    Two questions, one honest answer each

    Most of what people search about this game's platforms boils down to two things: can I play it on my phone, and will it run on what I already own. The answers are no and almost certainly yes, and neither needs hedging.

    There is no Android build and no iOS build. Steam's platform field for appid 4594150 returns Windows and Linux, with macOS explicitly false, and none of the twelve official announcements between May and August 2026 mention a phone or tablet version. The developer has not teased one, dated one, or been asked publicly in a way they have answered.

    On the PC side, the requirements are unusually light. The install is 200 MB. The minimum and recommended columns are identical except for one line. The only thing that can actually block you is Vulkan 1.3 driver support, which is a driver-age question rather than a hardware-power question.

    Why the mobile question keeps getting asked

    The store data explains it. Steam tags this game with Mouse Only Option, Playable without Timed Input and Save Anytime — the exact feature profile people associate with phone games. Nothing about how it plays requires a keyboard or an uninterrupted session.

    That instinct is reasonable, and it is why search suggestions for the game include mobile download and mobile free download. Those pages exist. They are not from Mumpitz Games, and we do not link to them.

    The handheld option that is real

    The game ships a native Linux build whose stated minimum OS is SteamOS 3.8 or similar — Steam Deck's operating system. Valve's compatibility report rates it Playable rather than Verified, and is specific about why.

    It passes both performance tests. It fails on controller glyphs not matching the Deck, and on interface text not being legible. For a game built around reading turret stats and upgrade costs, that second failure is the one that matters, which is why the Deck page here spends more time on it than on frame rates.

    What is in this section

    Read mobile and Android if you arrived from a search for a phone version, an APK, or a free download — it explains what those sites are and what the actual handheld path looks like.

    Read update history for every post-launch patch in one place — including the 18 August 2026 update and the level editor Mumpitz Games says is in the works — and Supporter Pack for what the $2.99 cosmetic DLC actually contains.

    Read PC and Steam Deck if you want the verbatim requirements table, an explanation of why Vulkan 1.3 is the only real gate, and the four individual Deck test results rather than just the badge.

    What is not here

    No benchmark numbers and no frame-rate figures, for any hardware. We have not run this game on a Deck or on integrated graphics ourselves, and Valve's compatibility report carries no published test date. We would rather point at the requirements and the refund window than invent performance data.
