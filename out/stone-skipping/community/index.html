    +1 Stone Skipping Codes, Meow Labs Group and Discord

    By Jellyfi · Last reviewed 2026-10-10 · Checked on version 2026-10-08 update

    Scope: Code search across the game description, the Meow Labs group page and the event listing on 2026-10-10 (UTC); group facts from the Roblox groups API; the social-links request returned 401 without a login and the group wall request returned 404, so neither could be read

    Key points

    • We saw no code in the official records we read on 10 October 2026: the game description, the Meow Labs group description, the group shout and five event listings. Whether the game has a code box is not confirmed.
    • The game belongs to the Roblox group Meow Labs, owned by iPlayfade, with 1,882,126 members at 05:20 UTC on 10 October 2026.
    • We could not confirm an official Discord: the social-links request returns 401 without a Roblox login, so we could not read the links.
    • A public server holds 10 players; we could not confirm whether private servers are offered.

    There are no +1 Stone Skipping codes we can confirm. On 10 October 2026 the game description, the Meow Labs group description, the group shout and the five official event listings contained no code, and the game's social links could not be read without a Roblox login. So this page lists zero codes and shows where we looked.

    Why not copy the codes other sites list?

    Because we could not trace any of them to an official Meow Labs post. Several fan sites publish code lists for this game. No code appears in the places above, and the developer's Discord, if there is one, needs a login we do not use for research. Whether the game itself has a code box is not confirmed, because we did not open the game. When a code shows up in an official source we will add a codes page that day.

    The group has about twice as many members as the game has favourites. We do not know why; the listing does not say whether joining the group gives anything in game.

    Is there an official Discord?

    We could not confirm one. The social-links request returns 401 ("Authentication token is missing") without a Roblox login, so we could not read the links. Roblox's documentation adds that social media links "are only visible to users who have verified their age as at least 16 years old". The group description holds a single word, "meow?". Unless you can see a link on the game's own Roblox page, treat any "official" invite with care, and never type your Roblox password anywhere except roblox.com.

    Can you play on a private server?

    We could not confirm it. The public listing gives 10 players per server, but its private-server field is unreliable, so open the Servers tab on the game page to see whether a private server option exists. Event windows are on the updates page.

    Is the game suitable for younger players?

    Roblox rates the experience "Maturity: Minimal" with the descriptor "Suitable for everyone". That label describes the content of the experience; it does not tell you how much a player could spend. +1 Stone Skipping sells 11 game passes and 90 developer products, and single items go up to 3,999 Robux, so it is worth agreeing a budget before a child plays. Every price is in the Robux shop guides.

    How can you make sure you are in the real game?

    Check three things on the game page before you spend Robux:

    1. The creator is the group Meow Labs.
    2. The title is +1 Stone Skipping. The description's first line calls it "+1 Skipping Stones"; both spellings are the developer's own.
    3. The icon uses the artwork below. The picture shows it on 2 October 2026 with a "WORLD 4" banner; at 05:22 UTC on 10 October 2026 the same artwork sat under a white hourglass and the words "12 HOURS", so the banner can differ.

    The real experience is universe 10765298801, with root place 111543903102439. Meow Labs has one public game, so a second "Stone Skipping" under another creator is not theirs.

    Where would official news appear first?

    The first three are channels the developer already uses; the fourth is empty so far:

    1. The Roblox event listing. ADMIN ABUSE + WORLD 5 was listed there on 26 September 2026, a week before the event, and the World 3 and World 4 updates had listings of their own. WORLD 6 + ADMIN ABUSE was listed on 3 October 2026, a week before its start time, and Halloween Event on 5 October, 12 days before its start time.
    2. The store. New passes and products were created on 15 different days within 30 calendar days (10 September to 9 October 2026), and both lists are public.
    3. The game description and icon. The icon carried a "WORLD 4" banner on 2 October 2026 and an hourglass with "12 HOURS" at 05:22 UTC on 10 October 2026.
    4. The group shout. Empty on 10 October 2026; the group had 1,882,126 members at our 05:20 UTC read.

    What you can do once you are in the game is covered in how to play.

    Send it with the place you saw it, ideally a screenshot of the game page or the group. The author page explains how we check and correct things.
