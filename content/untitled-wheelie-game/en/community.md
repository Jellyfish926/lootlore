# Untitled Wheelie Game Group, Discord and Codes Info

The official home of Untitled Wheelie Game is the Roblox group Untitled Wheelie Group, which owns the game and calls itself the "Official Group". It had 911,522 members on 10 October 2026. Third-party guides link a Discord invite made by an account with the owner's name; we could not confirm it from Roblox itself, and we list no codes.

## Which Roblox group is official?

Only one group owns the game, and the Roblox API names it as the creator. Its public details on 10 October 2026:

| Detail | Value |
| --- | --- |
| Name | Untitled Wheelie Group |
| Group description | Official Group |
| Owner | fireblock373 (display name "fire") |
| Members | 911,522 |
| Joining | Open to anyone |
| Pinned announcement | None |
| Public games | This game only (the group also owns 33 other experiences that are not public) |

You can find it on Roblox as [Untitled Wheelie Group](https://www.roblox.com/communities/84540135/Untitled-Wheelie-Group). Neither the group nor the owner account carries Roblox's verified badge, so check the group number (84540135) in the address bar rather than trusting the name alone.

## Is there an official Discord server?

Roblox shows an experience's social links only to signed-in users, and the public data we can read does not include a Discord address. Code sites link discord.com/invite/QHuDU7GHSB and call it the official server. In Discord's invite record, read on 10 October 2026, the invite was created by a Discord account named fireblock373, matching the group owner's Roblox name, and the server calls itself "Untitled Wheelie Game Official". That is good evidence but not proof. Check the social links on the Roblox page while signed in to be sure.

Our advice: open the [game on Roblox](https://www.roblox.com/games/93844268955707/Untitled-Wheelie-Game) while signed in and use the social link buttons on that page. A link found there comes from the developer; a link on a random site may not.

## Is there an Untitled Wheelie Game testing server?

People search for one. The group's public game list held one experience when we read it on 10 October 2026, so we found no separate public testing game. One event listing bears on the question: "FULL GAME RELEASE" gives a start of 23 July 2026 at 20:00 UTC, and its description reads "The full game will be set to release on july 23, 1:00PM MST (4:00 PM EST)!". The group has a Tester role with one member; how testing is run is not confirmed.

## Are there Untitled Wheelie Game codes?

Not that we can confirm. On 10 October 2026 the game description contained no code, the group shout was empty, the group wall request returned a 404 error and none of the seven event listings carried a code. Code lists exist on third-party sites; we could not trace them to a developer post we can read. We only publish a code after seeing it in an official source; until then, check the group page and the social links on the game page yourself.

## How do you avoid the wrong game?

Another Roblox experience is made by Wheelie District Studios. Its listing name was "🏍️ Wheelie District" when we read it on 10 October 2026 and "[AI COPS + MORE👮] Wheelie District 🏍️" on 30 September 2026. Codes written for it do not apply to this game. The quickest check is the creator line on the Roblox page: this game says Untitled Wheelie Group. The [cops and fines guide](/untitled-wheelie-game/cops-fines/) covers the police side of this game.
