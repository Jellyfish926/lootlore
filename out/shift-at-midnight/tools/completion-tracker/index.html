    Shift At Midnight 100% completion tracker

    Last verified 5 August 2026 · game version: 29 July 2026 patch

    Every achievement, ending, named threat and fixed story beat this wiki can source, in one checklist. Your ticks save in this browser — and an export code carries them to another device without an account.

    Your completion

    0 of 46 · 0%

    46 tick boxes across 7 categories, every one of them traceable to a page on this wiki. Ticks save in this browser only — no account, nothing uploaded.

    Nothing ticked yet

    Start anywhere. The bar above and each category bar update as you go.

    The checklist

    Achievements

    0 / 10

    All 10 Steam achievements. This is the complete set — Steam lists 10 and we track 10, read on 2026-09-21. Three of them are hidden in-game.

    Endings

    0 / 3

    Three outcomes, decided by two variables. They are mutually exclusive inside one run, so this category takes a minimum of three completed playthroughs.

    Run milestones

    0 / 7

    The fixed beats of a run, plus the modes that sit either side of it. Everything else in Story Mode is procedurally generated, so there is nothing else here that is the same for two players.

    Bestiary

    0 / 9

    Every named threat on this wiki — including the two that people search for as monsters and are not: one is an object, one is a customer.

    Counter toolkit

    0 / 5

    The five checks the job gives you. Not tracked by the game; tick one when you have actually caught something with it.

    The seven categories of tell

    0 / 7

    Catch a doppelganger by each kind of contradiction. Also not tracked by the game.

    Named doppelgangers documented here

    0 / 5

    5 of a reported 47. DualShockers has documented 47 named doppelgangers; this wiki names five, so this category is deliberately partial and always will be until we can verify more.

    How to use this, and where the list comes from

    Tick a box and it is remembered in this browser under a single key. Nothing is sent anywhere, there is no account, and closing the tab loses nothing. The trade-off is that browser storage is per-device: your phone and your desktop keep separate lists, and clearing site data wipes it. That is what the progress code is for. Export produces a short string that encodes exactly which boxes are ticked — paste it into the same box on another device, hit Load this code, and the two match. The code is a base64 bitmap of this page's fixed item order: no name, no account, nothing identifying.

    The list is assembled from this wiki's own pages. This tool's own achievement data file was last re-read from the Steam achievement stats page on 2026-09-21 and refreshes weekly by this site's build; the achievements page carries the full list with unlock rates and may reflect an earlier read than that date — check the achievements page itself for its own as-of date rather than assuming the two are in lockstep. The three endings, and the conditions that separate them, come from endings. The bestiary entries are the named threats on monsters. The counter toolkit, the seven categories of tell and the five named doppelgangers all come from identifying doppelgangers. Every item name is a link back to the page it came from, so you can check any line against its source.

    Where this list is knowingly incomplete

    A tracker that pretends to be exhaustive is worse than one that admits its edges.

    • Named doppelgangers: 5 of a reported 47. DualShockers documented 47; this wiki names five, because listing all of them in advance replaces the game with a lookup table — and because we have not verified the rest. See the identification guide.
    • Weapons: no per-weapon list exists here. Locked And Loaded asks you to buy every melee weapon, but no published list of those weapons or their prices could be verified, so there is one tick box for the achievement and none for individual weapons. See weapons.
    • No collectibles, no codes. There is no documented collectible system, and no official console commands or cheat codes exist — lists of "item IDs" for this game are not traceable to the developer. See cheats and console commands.
    • No per-night checklist. Shifts are procedurally generated, so a night-by-night list would describe one person's run. Only the fixed beats are in the milestones category. See nights and shifts.
    • Endless Mode is still a beta. The finished version is a free Q4 2026 update. If it adds achievements or named threats, they get added here with a date on them.

    New to the game and unsure where to begin? Start here orders the pages by what you need first. If you would rather track only the ten achievements with their global unlock rates attached, the older achievement tracker does exactly that.
