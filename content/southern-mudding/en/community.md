# Southern Mudding Codes, Group and Discord: What Is Official

The official home of Southern Mudding is the verified Roblox group of the same name, which owns the game and had 649,071 members at 11:20 UTC on 2 October 2026. Its description offers one reward: "Join the group for a free pickup truck!". We found no codes in any official source and could not confirm a Discord server.

Codes and a Discord link are among the first things Google suggests when you type the game's name. This page answers both from official sources only, and says plainly where we could not look.

## Are there any codes?

None that we can confirm. We checked the three official places that can be read without signing in:

| Official source | What it contains | Any code? |
| --- | --- | --- |
| Game description | Welcome text, the 25 September update notes, "Updates every Friday!" | No |
| Group description | "Join the group for a free pickup truck!" | No |
| Group shout | Empty | No |

Whether the game even has a box for entering codes needs an in-game check; nothing in the description mentions one. Until a code appears somewhere the developer controls, we will not list any, and we do not copy codes from other sites. A code that does not work costs you time and tells you the page was not checked.

## What is the free pickup truck?

It is the group reward, and it is the closest thing to a code this game has. The full official text is the group description: "Join the group for a free pickup truck!". The group accepts new members without approval, so joining takes one click on Roblox.

What the text does not say:

- which pickup truck you receive;
- whether you must join before entering a server or rejoin afterwards;
- where it shows up in the spawn menu.

Join first, then load the game, and look for a new entry among the pickup trucks. If it does not appear, try rejoining the server; we have not confirmed that this is needed. The [vehicle overview](/southern-mudding/vehicles/) lists the other ways to add vehicles.

## Is there an official Discord server?

We could not confirm one from public data. Roblox lets a developer attach social links to a game and to a group, and both lists returned an "Authentication token is missing" error to an anonymous reader. The game description contains no link, and the group shout is empty.

Signing in is not enough on its own. [Roblox's documentation](https://create.roblox.com/docs/en-us/production/promotion/social-media-links) states: "Social media links are only visible to users who have verified their age as at least 16 years old." If you meet that condition, check the Southern Mudding game page; a link listed there is the developer's own. We do not publish an invite we could not trace to that page.

## How can you follow updates without Discord?

Roblox's event system works without any outside account. The developer keeps an event listing for each weekly update, and most carry the text "Follow to be notified when the update drops!". At 11:23 UTC on 2 October 2026 the listing for that day's update had 43,785 accounts marked as going. [Roblox's documentation](https://create.roblox.com/docs/en-us/production/promotion/experience-events) says players who click Notify Me on an upcoming event "will receive stream notifications in their Roblox inbox when the event starts".

The [update schedule page](/southern-mudding/updates/) lists the event times and converts them to US and UK time.

## What about scripts and exploits?

Google also suggests "script" for this game. We do not cover exploits. Roblox's [Community Standards](https://about.roblox.com/community-standards) say it does not allow "Using or sharing exploits to help yourself or others gain an unfair advantage anywhere on the platform". Everything the guides on this site describe can be done with the normal game client. Start with the [how-to-play guide](/southern-mudding/how-to-play/) instead.
