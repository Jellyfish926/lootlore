    Deep Fishing Discord, Roblox Group and Wiki Links

    By Jellyfi · Last reviewed 2026-09-29 · Checked on version 2026-09-28 update

    Scope: Group and experience data from Roblox APIs; Discord data from Discord's public invite endpoint, all on 2026-09-29

    Missing something?

    Key points

    • Deep Fishing is made by a Roblox group owned by the verified account JoJocraftHP and named LazyGames.
    • The game's own description asks players to join the group for rewards and updates.
    • A Discord server named Deep Fishing describes itself as the official server; we could not see the Roblox page's social links to cross-check it.
    • There is no official wiki; the Fandom wiki had two empty pages when we checked.

    The Roblox group behind Deep Fishing had 269,222 members on 29 September 2026 and is owned by the verified account JoJocraftHP. Its name is LazyGames. The game's description tells players to join that group "for rewards and updates". A Discord server called Deep Fishing describes itself as the official one; there is no official wiki.

    This page records exactly what each link is, what it said on the day we checked, and which parts we could not confirm.

    Which Roblox group makes the game?

    The experience's creator field on Roblox points to one group, and that group describes itself as the game's home.

    The name includes a full stop — "LazyGames." — which is an easy way to tell it apart from look-alike groups. The group had no pinned shout when we checked.

    Why join the group?

    Because the developer says so. The last line of the official description reads: "Like the game, favorite it, and join the group for rewards and updates!" What the group reward is exactly is not stated there. Fan sites describe it, but we have not confirmed the details, so check in-game after joining.

    The store also has "Skip Gift" products, which suggest a timed gift system; our Robux shop guide lists them.

    Is there an official Discord server?

    There is a Discord server that says it is official. Discord's public invite data for the invite code fxjhB8BHeh shows:

    FieldValue on 29 Sep 2026

    Custom invite namedeepfishing

    What we could not do: Roblox only shows an experience's social links to signed-in users through its API, so we could not confirm that LazyGames links this exact server from the game page. Treat it as "the server that calls itself official" until you see the link on the Roblox experience page yourself while signed in.

    Never enter your Roblox password on a site that claims to hand out codes or items through Discord.

    Where do codes get announced?

    Nowhere we could read. The official description and the LazyGames group carry no codes, and the Discord announcement channels need a Discord account. The codes page records what each official Roblox record held on 10 October 2026. We do not copy code lists from other sites, because we could not find any code in the official Roblox records we read on 10 October 2026. When we can confirm a code from an official post, it will go on that page.

    Is there an official wiki?

    Not an official one. The Fandom wiki at deepfishing.fandom.com contained only two pages, both placeholders, when we checked. Two independent fan wikis exist (deepfishing.wiki and deep-fishing.wiki). This guide covers the same ground from official Roblox data: start with how to play, the badge list or the rod list.
