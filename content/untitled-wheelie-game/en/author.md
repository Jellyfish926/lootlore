# Author: Jellyfi, Editor of Untitled Wheelie Game Guides

Jellyfi is the editorial byline on {{BRAND}}, responsible for researching, publishing and maintaining the [Untitled Wheelie Game guides](/untitled-wheelie-game/) on this site. That means checking every fact against official Roblox data, dating each page, and correcting errors when readers report them. Every guide published under that byline is listed below.

## How these guides are researched

The game is on Roblox, so the most reliable facts come from Roblox itself: the official game description, the game's public statistics and content rating, its game passes and developer products, and the developer group's own page. Community sites, videos and code lists are used to find leads and cross-check, never as the only source for a fact.

![The Untitled Wheelie Game icon: a rider in a black helmet pops a wheelie on a mini bike with a red exclamation mark](icon "Every guide in this section is published under one editorial byline")

That ranking decides what gets published. If a detail — a bike stat, a fine amount, a control, a code — only appears on community sites, it stays out of the published guides until it can be checked in the live game or in an official post.

## How codes are handled

Codes are only listed after being seen in an official source for the game. When a code leaves that source it is marked expired and kept on the page with the date it was noticed, rather than deleted. On 30 September 2026 no code could be confirmed, so there is no codes page yet — the [community page](/untitled-wheelie-game/community/) explains why.

## How to read the dates on a page

Under the heading of each article, "Published" is the date the page went live on this site and "Last checked" is the date the text was checked against its sources. Roblox games update without version numbers, so these dates are the best guide to how fresh a page is. Prices and counts, such as those on the [game pass list](/untitled-wheelie-game/gamepasses/), are snapshots from the check date.

## Reporting an error

If a price, a number or a rule does not match the game you are playing, email us through the [Contact](/contact) page and include the page link. The site-wide writing and correction rules are on the [Editorial Policy](/editorial-policy) page.
