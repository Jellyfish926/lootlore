# 关键词清单（Southern Mudding，英文）

需求证据：2026-10-02 Google 下拉实测（`raw/suggest.txt`）+ 两个专站承接的词（`benchmark.md`）。
- 有下拉的词根：discord、map、codes、update（update today / new update / next update / when does … update / what time does … update）、houses、tornado、script、wiki。
- 下拉为空的：gamepass、limited、nitrous、badges、utv、6x6、trailer、money、free truck、best truck。
- 搜索量：**未获取**（Semrush 按任务边界未用）。不估算。
