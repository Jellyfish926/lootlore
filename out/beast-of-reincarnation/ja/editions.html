    Beast of Reincarnation エディション・予約特典まとめ

    各ストアの掲載内容を 2026年8月31日 に再確認

    言語: 日本語EnglishFrançaisEspañolItalianoDeutsch

    購入ガイド

    スタンダード、デジタルデラックス、それともコレクターズエディション？　全エディションの内容、確定済みの通常版価格 ¥8,980（税込）／$59.99、予約特典、そして Game Pass 勢がお金を払う前に知っておくべき1つのポイントを解説します。

    要点まとめ: 『Beast of Reincarnation』は2026年8月4日にPS5・Xbox Series X|S・PC（Steam／Microsoft Store）で発売。通常版は¥8,980（税込）で、どのエディションを選んでもゲーム本編の中身は同一です。差が付くのはスキンや琥珀といったボーナスアイテムだけ。さらに Game Pass Ultimate 加入者なら、発売初日から追加出費ゼロで遊べます。

    エディション早見表

    エディション価格内容
    スタンダード（ダウンロード版）¥8,980（税込）ゲーム本編。PS5・Xbox Series X|S・PC（Steam／Microsoft Store）向け。
    デジタルデラックスエディション通常版より高め（各ストアで要確認）本編＋クゥのスキン「黒柴犬」「茶柴犬」、エマの笠「鬼の笠」、刀「北斗星」、琥珀100,000、数種類の作物の苗。
    PS5 パッケージ版（ハピネット）¥8,980（税込）本編ディスク＋デジタルデラックスエディションと同内容のDLCプロダクトコードを封入。全国のゲーム取扱店・オンラインショップで予約受付中。
    予約特典（全エディション共通）予約すれば無料クゥのスキン「茶柴犬」＋琥珀30,000。

    2026年8月31日時点のラインアップは以上で全部です。ゲームフリーク初の完全オリジナルAAAアクションRPGを発行する Fictions, Inc.（国内パッケージ版はハピネットが担当）は、昨今のビッグタイトルとしては珍しいほどシンプルな構成にまとめてきました。価格帯は1つ、デラックスは1段階、パッケージはPS5のみ。ストーリーの章や難易度設定、ゲームモードが上位エディション限定になる、といった売り方は一切ありません。なお、フィギュアやアートブックを同梱した豪華なコレクターズエディションは現時点で未発表です。

    デジタルデラックスエディションの中身

    『Beast of Reincarnation』のデラックス版に追加されるのは、見た目替えのアイテムと序盤の軍資金がすべてです。国内ストアの商品ページで確認できる同梱物は次の通り。

    • クゥのスキン「黒柴犬」「茶柴犬」 — 相棒の犬クゥの毛色を変える外見スキン。性能への影響はなく、どの毛色でもクゥは変わらず戦い、道を嗅ぎ分け、指示に応えてくれます。
    • エマの笠「鬼の笠」 — 主人公エマ用の被り物。鬼の角をあしらった意匠で、穢れに覆われた終末後の日本という世界観によく馴染みます。
    • 刀「北斗星」 — エマ用のボーナス武器（英語版ストアでは「Big Dipper」表記）。序盤武器との性能差があるのかは未発表のため、当面は「見た目の選択肢が増える」程度に考えておくのが無難です。
    • 琥珀 100,000 — ゲーム内通貨のまとまった軍資金。序盤の強化や物資の調達に回せます。
    • 数種類の作物の苗 — 本作の栽培システムで使えるスタート用の種苗。

    いずれもゲームの根幹には影響しません。本作は『SEKIRO』の系譜に連なる弾き（パリィ）主体のアクションRPGで、刃を合わせ、体勢を崩し、一気に畳みかける——この駆け引きだけは琥珀では買えません。育成はスキルツリー・装備・スピリットストーン（Spirit Stones）の3本柱で、遠距離・隠密・正面強攻という3通りの構築はどのエディションでも最初から選べます。琥珀100,000が序盤をどこまで楽にするかは、発売後に実際にプレイして検証のうえ追記する予定です。

    予約特典と「重複」の扱い

    どのエディションでも、予約すればクゥのスキン「茶柴犬」と琥珀30,000が付いてきます。デジタルデラックスエディションを予約した場合、「茶柴犬」スキンそのものは重複しますが、琥珀は30,000＋100,000で合計130,000からのスタートになります。

    予約前に押さえておきたいのは、本作に体験版がないこと。発売から4週間が経ってもどのプラットフォームにも配信されていません。Xbox Developer Direct（2026年1月22日）や各種トレーラーで実機映像は公開済みで、Game Informer や GameSpot など海外メディアの先行試遊の反応は「慎重ながら好意的」というトーンですが、迷っているなら発売後のレビューを待ってからでも遅くはありません。犬のスキンと琥珀30,000のために焦って予約するほどの特典ではない、というのが正直なところです。

    PS5パッケージ版と店舗特典——国内勢の本命

    国内ではハピネットからPS5パッケージ版がダウンロード版と同日の8月4日に発売されます。価格は同じく¥8,980（税込）で、4月20日から全国のゲーム取扱店・オンラインショップで予約受付中。最大のポイントは、デジタルデラックスエディションと同内容のDLCプロダクトコードが標準で封入されることです。初回出荷限定ではなく恒久的な封入仕様のため、デラックス相当のアイテム一式を最も安く揃える方法は、実質このパッケージ版ということになります。

    さらに店舗ごとの予約特典グッズも豊富です。電撃オンラインのまとめによると、主な特典は以下の通り（2026年8月31日時点）。

    エビテンファミ通DXパック（キャンバスボード、アクリルパネル、アクリルスタンドなど）
    アキバ☆ソフマップB2タペストリー
    AmazonオリジナルA4クリアファイル
    あみあみアクリルキーホルダー

    このほか Joshin、ビックカメラグループ、ヨドバシカメラなどでも特典が用意されています。絵柄や仕様は変更・品切れの可能性があるため、予約前に各店舗の商品ページで最新情報を確認してください。

    Game Pass と Play Anywhere——そもそも買う必要がある？

    『Beast of Reincarnation』は Game Pass Ultimate で発売初日から配信されます。しかも Xbox Play Anywhere 対応のため、Xbox と PC でライセンス・セーブデータ・実績が完全共有。Series X でボスに挑み、続きを PC で遊ぶ、という使い方が追加購入なしで成立します。携帯ゲーミングPC向けの最適化（Handheld Optimized）とクラウドゲーミングにも対応します。

    Xbox・PC 勢にとって、これは購入判断を根本から変える話です。すでに Ultimate に加入しているなら本編は実質タダ。お金を出す理由があるとすれば、デラックスのスキンや琥珀がどうしても欲しい場合だけです。なお、デラックス相当のコンテンツはデラックスDLC(9.99 ドル)として単品販売されていますので、Game Pass 勢でも特典アイテムだけを買い足せます。

    一方、PS5 には Game Pass に相当する選択肢がありません。PS5 勢の検討軸は、ダウンロード通常版・デジタルデラックス・パッケージ版の3択になります。

    結局どれを買うべき？

    • Game Pass Ultimate 加入者 — 何も買わずに初日から Xbox／PC でプレイ。Play Anywhere でセーブも共有されます。出費を検討するのは、デラックスの見た目アイテムがどうしても欲しい場合だけ。
    • PS5 でダウンロード派 — 通常版¥8,980が基本線。クゥの毛色替えと琥珀の初期資金に魅力を感じるならデラックスへ。中身のゲームは全エディション共通です。
    • ソウルライク経験者 — デラックスはスキップ推奨。弾き主体の戦闘は結局プレイヤーの反応速度が全てで、特典装備がヌシ戦の歯応えを損なうことはありません。
    • コレクター・特典重視派 — デラックス同等DLCが封入される PS5 パッケージ版が最有力。店舗特典のグッズで予約先を選ぶ楽しみもあります。

    節約ポイント: 発売日に最安で遊ぶなら Xbox／PC の Game Pass Ultimate。パッケージで最も得なのは、デラックス同等DLCコードが封入される国内PS5パッケージ版です。

    よくある質問

    体験版はある？

    ありません。発売から4週間が経った現在も、全プラットフォームで体験版は配信されていません。Xbox・PC なら Game Pass、Steam なら返金制度が実質的なお試し手段になります。

    デジタルデラックスエディションを買うとゲームが楽になる？

    ほぼ変わりません。スキンと笠は完全に外見のみ。琥珀100,000は序盤の資金繰りを助けますが、本作の戦闘は弾きの精度がものを言うスキルベースの設計で、お金でパリィのタイミングは買えません。

    価格はいくら？

    通常版はどのプラットフォームでも¥8,980（税込）。海外では$59.99／59,99 €で、フルプライスが$69.99へ上がりつつある昨今のAAAタイトルとしては一段安い設定です。

    豪華なコレクターズエディションはある？

    フィギュアやアートブックを同梱した限定版は未発表です。現時点でコレクター向けの選択肢は、PS5パッケージ版＋各店舗の予約特典グッズ(キャンバスボード、アクリルスタンドなど)になります。

    Game Pass で遊ぶ場合、デラックスのアイテムだけ購入できる？

    できます。デラックス相当の内容はデラックスDLC(9.99 ドル)として単体で販売されており、スタンダード版や Game Pass 版からのアップグレード用として購入できます。詳しくは予約特典まとめへ。

    Xbox 向けのパッケージ版は国内で出る？

    国内で発表されているパッケージ版は、ハピネットの PS5 版のみです。Xbox Series X 向けパッケージ版の国内展開は未発表です。
