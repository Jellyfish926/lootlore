4:T666,<p>Eleven achievements, no hidden ones, and a list short enough that the tracker above is really a planner: tick what you have and it tells you which of the rest the most players have managed — the statistically cheapest next step — and which one almost nobody has. Ticks stay in this browser only; Reset clears them.</p>
<h2>Reading the numbers</h2>
<p>The percentages are Steam's global unlock rates for Sir, We Have an Orc Problem, refreshed weekly by this site's build with the capture date printed under the list. On the 7 September read the top is <strong>Gotta Start Somewhere</strong> (survive 1.1) at 97.4% and the bottom is <strong>Four-tified</strong> (survive 6.1 with only four turret types and no abilities) at 12.2%; <strong>Against All Odds</strong>, surviving 6.2, sits at 30.2%, which means clearing the campaign already puts you past roughly 70% of owners. The <a href="/levels/all-achievements/">full achievements page</a> has the same list with which level each one is realistically done on.</p>
<h2>Why four turret types is rarer than one</h2>
<p>The list has an inversion that trips people up: using four turret types (Four-tified, 12.2%) is rarer than using three (Triple Threat, 17.2%), which is rarer than using one (Specialist, 22.5%). The constraint sounds looser as the number rises, but the number is a proxy for the level you are asked to do it on — one turret on 1.1 against four on 6.1, with abilities forbidden in every case. The <a href="/towers/turret-roles/">turret roles</a> page explains why a single upgraded laser holds 1.1 and why 6.1's multiple approach routes need a real composition.</p>5:T5ae,<h2>A sensible order</h2>
<p>The tracker's "easiest next" will walk you through the same order the community guide recommends. Progression first — 1.1, 3.1 and 6.2 come from simply finishing the campaign. Then <strong>Overkill</strong>, the 666k single-nuke, which needs patience with a bunched wave more than anything else; the <a href="/towers/abilities/">abilities page</a> covers how to line one up. Then <strong>Fine, I'll Do It Myself</strong>, the no-turret run, which is a test of your ability <a href="/towers/upgrade-grind/">upgrades</a> rather than reflexes, and <strong>Fully Loaded</strong>, which is a grind rather than a challenge.</p>
<p>Leave the no-ability constraints for last, in rising order of level: One Is Enough (1.1), Specialist (3.1), Elemental Carnage (4.1 with only Flamethrower, Tesla Coil and Cryo Beam), Triple Threat (5.1), Four-tified (6.1). Each one is a placement puzzle on a specific map, and the <a href="/towers/all-turrets/">all turrets</a> stat table is the reference for which combinations have the penetration to hold a lane without abilities.</p>
<h2>What this tool is not</h2>
<p>It does not read your Steam profile — you tick the boxes, which is why it works without signing in and cannot be wrong about what you own. With only eleven entries the value here is the ordering, not the bookkeeping: the tracker always names the cheapest remaining unlock, and for this game that order is worth following.</p>7:["category","levels","d"]
