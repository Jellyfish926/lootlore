共通の予約特典(全ストア)

デジタル版を予約購入すると、エディションを問わず以下が付属することが各ストアの商品ページで確認されています。

特典内容
クゥのスキン「茶柴犬」相棒クゥの見た目を茶色の柴犬に変更できる外観スキン。性能への影響はありません。
琥珀(アンバー)×30,000ゲーム内通貨。序盤の装備・素材調達がわずかに楽になる程度の額で、バランスを壊すものではありません。

デジタルデラックスエディションの全内容

デジタルデラックス版には本編に加えて、以下のボーナスコンテンツが含まれます(PlayStation Store / Xbox ストアの掲載内容)。

アイテム種類
クゥのスキン「黒柴犬」「茶柴犬」外観スキン2種
エマの帽子「鬼の帽子」装備(外観・装飾)
エマの剣「北斗星」武器
琥珀(アンバー)×100,000ゲーム内通貨
作物の苗 数種育成用アイテム

デラックス特典は「ちょっとした先行スタート+着せ替え」の域を出ない構成です。ソウルライク経験者で特典自体に魅力を感じないなら、エディション比較でも書いたとおりスタンダード版で十分です。

PS5 パッケージ版:永久封入特典

国内では Happinet からPS5 パッケージ版の発売が決定しており、永久封入特典としてデジタルデラックス相当のボーナスDLCを入手できるプロダクトコードが同梱されます。「予約しないと消える初回特典」ではなく永久封入なので、発売後にゆっくり買っても特典を逃さないのがパッケージ版の利点です。

店舗別グッズ特典(パッケージ版)

国内報道(電撃オンラインほか)では、店舗別のオリジナルグッズ特典としてオリジナルキャンバスボード、ネックストラップ、アクリルスタンドなどがラインナップされていることが確認されています。どの店舗がどのグッズかは配布状況が変動するため、予約時に各店舗の商品ページで最新の記載を確認してください。確定し次第、本ページに店舗別の一覧表を追記します。

Game Pass 勢への注意:本作は発売初日から Game Pass に対応しますが、Game Pass 版に予約特典・デラックス特典は含まれません。柴犬スキンや「鬼の帽子」が欲しい場合は、各ストアでアップグレード/アドオンとして購入できるかを発売日に確認する必要があります。詳しくは Game Pass 対応まとめ へ。
