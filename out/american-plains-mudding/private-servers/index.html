    American Plains Mudding Private Server Commands Guide

    By Jellyfi · Last reviewed 2026-10-09 · Checked on version 2026-10-03 update

    Scope: The Premium Private Servers game pass description, its gift product and one badge text, read from Roblox's public APIs on 2026-10-09. The description says its list is partial. Where commands are typed, the full command list, commands available without the pass, and how a private server is created or what it costs, are not published and are not covered.

    Premium Private Servers commands

    Quick facts

    The three commands printed in the Premium Private Servers game pass description; the description says they are "Some of what is included".

    Description
    :weather storm 1, Spawns Tornadoes, Ranges From 1-10 · :fly user, Fly Any User · :admin user, Give Commands To Any User
    Requires
    Premium Private Servers game pass (195 Robux on 9 October 2026)

    Key points

    • The developer has published three commands, all in the Premium Private Servers pass description: ":weather storm 1", ":fly user" and ":admin user".
    • The storm command "Spawns Tornadoes" and "Ranges From 1-10"; the description does not say what the number controls.
    • The pass costs 195 Robux and also gives "2x Spawn Slots In Private Servers, Up To 16".
    • The description introduces the list as "Some of what is included", so more commands may exist; we list only the three in official text.

    The only American Plains Mudding commands the developer has published are three lines in the Premium Private Servers pass description: :weather storm, :fly and :admin. The pass costs 195 Robux and also doubles spawn slots in private servers, up to 16. The description calls its list "Some of what is included".

    So this is a short page by design. Players search for longer command lists, but we found none published by the developer, and we have not tested any commands in game. Nothing beyond these three is repeated here.

    What commands does the pass list?

    The description opens with "Improve The Private Server Experience!" and then gives four lines under "Some of what is included:". Three are commands, copied here as printed.

    Command as printedWhat the description says it does
    :weather storm 1Spawns Tornadoes, Ranges From 1-10
    :fly userFly Any User
    :admin userGive Commands To Any User

    The fourth line is not a command: "2x Spawn Slots In Private Servers, Up To 16, All Admins In Your Server Have This Ability".

    Each command starts with a colon. In the second and third, "user" is presumably a placeholder for a player's name; the description does not show a worked example. It also does not say where commands are typed.

    How does the :weather storm command work?

    The printed form is ":weather storm 1", and the note beside it reads "Spawns Tornadoes, Ranges From 1-10". So the number at the end can be anything from 1 to 10, and the example uses the lowest value.

    What the number controls is not stated. It could be how many tornadoes appear or how severe the storm is. Both readings fit the words, and only a test in a private server would settle it.

    Tornadoes are not limited to this command. A badge called Tornado Survivor, for having "Experienced a tornado in APM and lived to tell the tale!", had been awarded 2,684,652 times by 9 October 2026. That is a large number for a feature tied to a paid pass, which suggests tornadoes also occur in normal play; we have not confirmed that in game. The badge guide has the full numbers.

    What do :fly and :admin do?

    Going by the description, ":fly user" lets you make any player fly, and ":admin user" lets you "Give Commands To Any User". The description does not say who may run :admin; presumably it lets a player with command access give it to another player, which we have not tested.

    That ties in with the spawn slot line, which says "All Admins In Your Server Have This Ability". Read together, the two lines suggest that an admin in your private server gets the doubled slots as well as commands. What makes a player an "admin" there is not spelled out.

    What else does Premium Private Servers include?

    Doubled spawn slots. In public servers the pass texts put the limit at four to eight slots, depending on which spawner passes you own. In a private server this pass makes that "2x", "Up To 16".

    WhereLowest figure in the stated rangeWith both spawner passes
    Public server48
    Private server with this pass8 (2 x 4, our arithmetic, not stated)16

    Only the public cap of 8 and the private cap of 16 are stated by the developer; the 8 in the private row of the first column is our multiplication of the lowest figure in the range, which the text does not confirm. The spawn slot guide explains the four spawner passes.

    How much does Premium Private Servers cost?

    ItemRobuxCreated
    Premium Private Servers (game pass)19516 Jun 2023
    [GIFT] Premium Private Servers (developer product)19515 Aug 2025

    It is the joint-cheapest of the eight passes on sale, level with Premium Trailers; the game pass guide compares them all. The pass upgrades private servers. It is not the private server itself. Roblox's Creator Docs describe a private server as "a subscription-based feature that allows a player to decide who can play a game with them", which a developer can make free or charge a monthly Robux fee for. The public game record shows createVipServersAllowed as false, so we cannot say private servers here follow that subscription model; how a private server is created in game is not published.

    Is there a full American Plains Mudding commands list?

    Not from the developer, as far as we can find. Google suggests searches such as "commands list", "admin commands", "advanced commands" and "private server commands" for this game, so plenty of players are looking. The official text stops at three commands and the words "Some of what is included".

    We would sooner publish three commands we can source than thirty we cannot. If the developer posts a complete list somewhere we can read, it will be added here with its source. The community page explains which official channels we could and could not reach.

    What should you check in game?

    • Where commands are entered
    • What the 1 to 10 value on :weather storm changes
    • Whether a command-spawned tornado awards the Tornado Survivor badge
    • Which commands, if any, work in a private server without the pass
    • Whether :admin lasts for the session or permanently
