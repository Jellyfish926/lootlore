System Requirements and Steam Deck Compatibility

Last verified 2026-08-12

Last reviewed: 1 September 2026 · Newest game update reflected: 2026.08.18.12.05 (18 August 2026). If your PC can do Vulkan 1.3, it can run this game. Everything else on the requirements list is trivially low: any 64-bit x86 processor, 4 GB of RAM, and 200 MB of storage. There is no GPU model named anywhere in the minimum spec.

That makes this one of the easier games to check compatibility for. You are not asking "is my card fast enough", you are asking "is my driver new enough", and those are very different questions.

The official requirements, verbatim

These come straight from the Steam store data, not from a spec-scraping site.

MinimumRecommended
OSWindows 10Windows 11
ProcessorAny x86_64 CPUAny x86_64 CPU
Memory4 GB RAM4 GB RAM
GraphicsVulkan 1.3 supportDedicated graphics card with Vulkan 1.3 support
Storage200 MB200 MB

Note what does not change between the two columns. The processor, memory and storage are identical; the only upgrade Mumpitz Games asks for is a dedicated GPU instead of integrated graphics. That is an unusually honest requirements table — most studios pad the recommended column.

Vulkan 1.3 is the only thing that can actually stop you

Vulkan 1.3 was released in early 2022. In practice that means a GPU driver from roughly 2022 onwards on NVIDIA, AMD and Intel alike.

If the game refuses to launch on hardware that looks powerful enough, the driver is the first thing to check, not the card. Older integrated Intel graphics and pre-2020 driver branches are the common failure case, and updating the driver fixes it more often than not.

There is no DirectX fallback listed, so this is not optional.

Linux and SteamOS

The game ships a native Linux build. Steam's Linux requirements name SteamOS 3.8 or similar as the minimum OS, with the same 4 GB / Vulkan 1.3 / 200 MB figures.

Naming SteamOS specifically in the Linux column is a deliberate signal. It means the handheld case was considered rather than left to Proton compatibility layers, which matters for battery life and for whether things break after a system update.

There is no macOS build. Steam's platform field returns mac as false, and no Mac requirements are published. Apple Silicon users have no supported path here.

The Steam Deck rating is Playable, and the reasons are specific

Valve's compatibility report resolves this game to Playable — the middle tier, below Verified. The report lists four individual test results, and reading them is more useful than the badge:

  • Default configuration is performant — pass
  • Default controller configuration is fully functional — pass
  • Controller glyphs match the Deck's device — fail
  • Interface text is legible — fail

So performance is not the problem and neither are the controls. What Valve flagged is presentation: the game shows the wrong button icons, and the interface text is too small at the Deck's screen size.

Whether that matters depends on how you play

For a shooter, wrong glyphs would be a nuisance and small text would be survivable. Here it is the reverse. This is a game where you read turret stats, upgrade costs and level numbers constantly — small text is the exact thing you cannot easily work around.

Players who care about squeezing the numbers will find the Deck frustrating. Players who already know their build and want to grind resources on the couch will barely notice, since the mouse-only control scheme maps cleanly to the trackpad.

If you want it handheld, it works. Go in expecting to squint at the upgrade tree.

What else the store data tells you

The game is single-player only with 11 Steam achievements, and it supports Steam Cloud and Family Sharing — so a save started on a desktop continues on a Deck without any manual copying.

It ships with 13 languages: English, French, Italian, German, Spanish (Spain), Dutch, Japanese, Korean, Polish, Brazilian Portuguese, Russian, Simplified Chinese and Traditional Chinese. That is broad for a small studio and suggests the text volume is low, which is consistent with a 200 MB install.

There is no official website listed on the store page. Steam's announcement feed is the only first-party channel we can point at, which is worth knowing if you go looking for patch notes.

What we cannot tell you

We have not benchmarked this ourselves on any specific hardware, and we do not have frame-rate figures for the Deck or for integrated graphics. Valve's report has no published test date, so we cannot say which build it was run against — and the game has already been updated once since launch, on 4 August 2026.

If a specific machine is borderline, the two-hour Steam refund window is a more reliable test than any requirements table, including this one.
