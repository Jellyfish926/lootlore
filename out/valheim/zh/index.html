    英灵神殿攻略：从新手开局到深北之境

    作者 Jellyfi · 发布 2026-09-17 · 最后核对 2026-09-17 · 核对游戏版本 1.0.12

    语言：中文English

    要点

    • 先判断自己处在哪个阶段，再解决眼前这一个问题，不必先读完整站。
    • 新存档从第一天、主线顺序、战斗入门和捡尸流程这四篇开始。
    • 感觉卡住而不是装备不够时，先查食物、休息好了和蜜酒，再考虑做新防具。
    • 主线顺序是青青草原 → 黑暗林山 → 沼泽 → 雪山 → 平原 → 迷雾之地 → 灰烬之地 → 深北之境。

    从第一座小屋，到深北之境的最终挑战。

    关于本攻略

    这里把英灵神殿的主要推进路线拆成能直接使用的攻略：先看自己处在哪个阶段，再解决眼前的一个问题。你不需要先读完一整本手册，也不需要照着一张装备榜机械地刷材料。

    第一次玩，从这里开始

    • 开局第一天：先完成工具、住所、食物与出生点。
    • 主线推进顺序：判断当前要做什么、下一片区域需要什么。
    • 战斗基础：学会防御、短连击与保留撤离体力。
    • 死亡后找回装备：把捡尸变成有准备的救援。

    继续你的主线

    • 黑暗林山：青铜时代 → 古树长老
    • 沼泽：地牢与采铁 → 邪骨恶灵
    • 雪山：抗寒与银矿 → 冰霜龙母
    • 平原：营地与农业 → 亚格鲁斯
    • 迷雾之地：驱雾与工作站 → 女王
    • 灰烬之地：登陆与前哨 → Fader
    • 深北之境：完整推进 → Intricate Key → Kall

    不确定卡在哪里？先看这几类问题

    总觉得打不过，不一定只差一件护甲。先检查食物、休息状态与蜜酒。

    资源拿到了却用不上，先看制作与修理；物资一直运不回家，检查传送门和航海路线。

    准备与朋友长期游玩，先约定联机与开服规则；从旧版本回归，先读1.0 存档选择与模组排查。
