## How do you redeem a BlockSpin code?

1. Join BlockSpin on Roblox with the account you want the cash on.
2. Open the game's Code window from the in-game menu.
3. Type W7C28D exactly as written — it is six characters, letters and digits.
4. Confirm, then check your cash balance.

We have not confirmed the exact button layout from an official source, so the steps above stay general. Code sites describe the Code window as sitting in a menu on the right-hand side of the screen. Community sites say W7C28D is entered in the referral-code tab of the Code window, not the normal code box; we have not confirmed this in-game.

## What if the code doesn't work?

Check these in order:

- **Is the account new?** The description says the $500 is "if you're a new player". An account that has played for a while may not qualify.
- **Did you type a lookalike character?** Re-type it rather than pasting from a site that may have added a space.
- **Has it already been redeemed on this account?** The description does not say whether a code can be used more than once.
- **Did the developers remove it?** Open the game page on Roblox and read the description. If W7C28D is gone, the offer has ended.

Code sites also report a "Could not validate your account" message on brand-new accounts that goes away after some playtime. We have not verified that message ourselves, so treat it as a lead, not a rule.
