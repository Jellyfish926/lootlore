# Roblox Stock Exchange 2 Discord, Group and Developer

Roblox Stock Exchange 2 is made by the Roblox group Summit Productions Development, which had 276,709 members on 8 October 2026. A Discord server named after the game calls itself the official server. We could not confirm that link from Roblox itself, because the game's social links cannot be read without a Roblox login.

This page records what each of those is, what it said on the day we checked, and what we could not see.

## Who makes the game?

The creator field on the game's Roblox record points to one group.

| --- | --- |
| Name | Summit Productions Development |
| Group ID | 33446529 |
| Created | 28 November 2023 |
| Members | 276,709 |
| Owner account | SummitGroupHoIder (account created 12 May 2024) |
| Verified badge | No |
| Entry | Open; anyone can join |
| Description | Empty |
| Shout | None |
| Roles | Guest, Member, Client, Staff, Contracted Developer, Developer, Operations Director, President, Holder |

Two things stand out. The owner account is called SummitGroupHoIder, and its own profile description is empty, so the group tells you little about who the developers are. And with an empty description and no shout, the group description and shout carry no codes. We could not read the group wall or any social links. This game's description does not mention a group reward. The Legacy game's description does offer a "$10,000 starting cash bonus" for joining "the Main Group"; that is the older game, not the sequel.

## What else has the group published?

Five public experiences are attached to the group. Visit counts are from 8 October 2026.

| Experience | Created | Visits |
| --- | --- | --- |
| Legacy: Roblox Stock Exchange | 23 May 2025 | 8,600 |
| INDEFINITE \| Dreamcore 🌫️ Backrooms 🚪 | 18 Nov 2025 | 14,346 |
| Rocket Wars Tycoon | 5 May 2026 | 512,502 |
| Roblox Stock Exchange 2 | 13 Jul 2026 | 5,093,566 |

The sequel is by far the largest. The oldest entry, Legacy: Roblox Stock Exchange, is the earlier game in the series, and its description still talks about its own features, such as an options chain that unlocks at two rebirths. Those lines describe the Legacy game. Do not assume they apply to the sequel; the [how-to-play guide](/roblox-stock-exchange-2/how-to-play/) sticks to the sequel's own description.

## Is there an official Discord server?

There is a server that says it is. Discord's public data for the invite code qR8v6Murp3 showed this on 8 October 2026:

| Field | Value |
| --- | --- |
| Server name | Roblox Stock Exchange 2 |
| Self-description | "Official server for RSE: Roblox Stock Exchange 2" |
| Members (approx.) | 1,231 |
| Online (approx.) | 182 |
| Invite expiry | None set |

One code site, Try Hard Guides, links the same invite. That is still a server describing itself, repeated by a third party. Roblox refused our request for the game's social links with a 401 error because we were not signed in, and its documentation says social media links "are only visible to users who have verified their age as at least 16 years old".

So the safe way to check is from inside Roblox. Sign in with an account verified as 16 or older, open the game's page and look for social links; the developer may not have set any. If a Discord link on the page leads to the same server, it is the developer's. Never type your Roblox password anywhere except roblox.com, and treat direct messages offering codes or free cash as scams.

## Where do official announcements appear?

In two places we can read. The game description carries one code and the like count it sets for another; the [codes page](/roblox-stock-exchange-2/codes/) follows it. Official Roblox events carry update announcements, and there have been 12 since 17 August 2026; they are all on the [updates page](/roblox-stock-exchange-2/updates/).

Two places we could not read: the group wall, where our request came back with a 404 error, and the Discord server's channels, which need a Discord account. Nothing on this site is taken from Discord messages.

## Is there an official wiki?

We found none. The game description and the group page mention no wiki. One independent fan site, robloxstockexchange2.wiki, had five pages when we checked and states that it is not affiliated with the developer. This guide is also unofficial. Every number here names where it came from.
