# Valheim Multiplayer & Upkeep Guides

Setting up a server? Read the co-op guide. Updating your version? Check the old-save page first. Hit a mod problem? Protect your data before you start diagnosing. None of these guides ask you to delete a live world just to test something, or to buy a particular hosting service.

## Pick a guide by problem


![The build menu open in front of a village of wooden Viking huts, listing roof, wall and stair pieces](ss08 "A village of wooden huts: these guides are about keeping a shared world running")
### [Co-op and server guide](/valheim/co-op/)

Choose between a temporary friend session and a dedicated server, run a join test, work through common connection problems, and set co-op rules you can keep to long term.

### [1.0 save and world choice guide](/valheim/save-1-0/)

Separates what an old save can keep doing from what has to be newly generated, with different upgrade choices for builders, returning players and achievement hunters.

### [Mods troubleshooting guide](/valheim/mods/)

Use backups, a vanilla test and staged restores to handle post-update launch failures, missing items and multiplayer mismatches, with no unverified compatibility promises.

## Scope

These guides assume vanilla standard survival. World modifiers, mods and later patches can change how things behave. Every page keeps its source links and check date, and combat plans are first-playthrough advice, not the only solution.
