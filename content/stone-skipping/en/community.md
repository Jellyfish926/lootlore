# +1 Stone Skipping Codes, Meow Labs Group and Discord

There are no +1 Stone Skipping codes we can confirm. On 10 October 2026 the game description, the Meow Labs group description, the group shout and the five official event listings contained no code, and the game's social links could not be read without a Roblox login. So this page lists zero codes and shows where we looked.

## Where did we look for codes?

| Official place | What we found on 10 October 2026 (05:20 to 05:22 UTC) |
| --- | --- |
| Game description on Roblox | No codes; it ends with "Like & Favorite if you enjoy the game!" |
| Meow Labs group description | One word: "meow?" |
| Group shout (pinned announcement) | None |
| Group wall | Could not be read; the wall request returned a 404 error with no message |
| Game and group social links | Request refused with 401 without a login |
| Official event listings (World 3, WORLD 4, ADMIN ABUSE + WORLD 5, WORLD 6 + ADMIN ABUSE, Halloween Event) | No codes in any title, subtitle or description |
| Public game page | No developer Discord, YouTube or X link in the page we could load |

## Why not copy the codes other sites list?

Because we could not trace any of them to an official Meow Labs post. Several fan sites publish code lists for this game. No code appears in the places above, and the developer's Discord, if there is one, needs a login we do not use for research. Whether the game itself has a code box is not confirmed, because we did not open the game. When a code shows up in an official source we will add a codes page that day.

## Is there an official Discord?

We could not confirm one. The social-links request returns 401 ("Authentication token is missing") without a Roblox login, so we could not read the links. Roblox's documentation adds that social media links "are only visible to users who have verified their age as at least 16 years old". The group description holds a single word, "meow?". Unless you can see a link on the game's own Roblox page, treat any "official" invite with care, and never type your Roblox password anywhere except roblox.com.

## Can you play on a private server?

We could not confirm it. The public listing gives 10 players per server, but its private-server field is unreliable, so open the Servers tab on the game page to see whether a private server option exists. Event windows are on the [updates page](/stone-skipping/updates/).

## Is the game suitable for younger players?

Roblox rates the experience "Maturity: Minimal" with the descriptor "Suitable for everyone". That label describes the content of the experience; it does not tell you how much a player could spend. +1 Stone Skipping sells 11 game passes and 90 developer products, and single items go up to 3,999 Robux, so it is worth agreeing a budget before a child plays. Every price is in the [Robux shop guides](/stone-skipping/robux/).

## How can you make sure you are in the real game?

Check three things on the game page before you spend Robux:

1. The creator is the group Meow Labs.
2. The title is +1 Stone Skipping. The description's first line calls it "+1 Skipping Stones"; both spellings are the developer's own.
3. The icon uses the artwork below. The picture shows it on 2 October 2026 with a "WORLD 4" banner; at 05:22 UTC on 10 October 2026 the same artwork sat under a white hourglass and the words "12 HOURS", so the banner can differ.

The real experience is universe 10765298801, with root place 111543903102439. Meow Labs has one public game, so a second "Stone Skipping" under another creator is not theirs.
